마스터 6-1. 신청 받기

사람들이 신청하는 곳을 먼저 만듭니다. 초보라면 A. 구글폼부터 — 코딩 없이 10분. 이게 있어야 카드뉴스·홍보에 신청 링크를 붙일 수 있어요.

⏱ 약 30분📥 입력 · 1단계 대상자·과정📦 결과물 · 신청 폼 + 신청 링크

💡 순서상 신청 받는 곳이 가장 먼저입니다. 링크가 있어야 그다음 카드뉴스·홍보가 의미 있어요.

1어디로 받을지 먼저 고르기

초보 강사는 A. 구글폼부터 시작하세요.

🔑 두 가지 길
• A. 구글폼 + 구글시트 — 코딩 없음, 10분, 링크만 공유. 응답은 시트에 자동 저장. 초보 추천.
• B. 슈파베이스 — 내 웹페이지 안에 직접 붙이고 자동화가 강함. 대신 조금 어려움(서버). 익숙해지면.
2🟢 A. 구글폼으로 받기 (쉬움·추천)

코딩 없이 신청 폼을 만들고, 응답을 구글시트에 자동으로 모읍니다.

  1. 아래 버튼 → 구글폼에서 빈 양식 만들기 (구글 계정)
  2. 질문 추가: 이름·연락처(단답), 관심 과정(객관식), 하고 싶은 말(장문)
  3. 오른쪽 위 응답 탭 → 초록 시트 아이콘 → 구글시트로 연결(응답 자동 저장)
  4. 보내기로 폼 링크 복사 → 카드뉴스·홍보 글에 붙이기
📝 구글폼 만들기 →
내 강의 신청용 구글폼에 넣을 질문과 안내 문구를 만들어줘. (구글폼에 그대로 옮겨 적게) - 대상자/과정: (1단계 대상자 + 과정명 붙여넣기) 질문은 꼭 필요한 것만: - 이름 (단답) - 연락처 (단답) - 관심 과정 (객관식 — 보기도 만들어줘) - 하고 싶은 말 (장문) 그리고: - 폼 제목과 첫 화면 설명 문구 - 제출 후 '감사합니다' 문구 - 연락처 수집 목적을 밝히는 개인정보 동의 한 줄 항목별로 정리해서, 복사해 붙이기만 하면 되게.
💡 구글폼은 코딩이 없고 응답이 구글시트에 자동으로 쌓입니다. 관리(6-3)도 그 시트에서 바로 할 수 있어요. 대부분의 초보 강사는 A로 충분합니다.
3🔵 B. 슈파베이스로 내 사이트에 직접 (조금 어려움)

내 웹페이지 안에 폼을 붙이고 데이터를 직접 저장합니다. 익숙해지면 하세요.

  1. 아래 버튼 → Start your project 가입(구글, 1분)
  2. New Project — DB 비번은 메모, 지역은 Northeast Asia(Seoul/Tokyo)
  3. Settings → API에서 Project URL · anon public 키 복사
🟢 슈파베이스 열기 →
너는 나를 1:1로 돕는 친절한 개발 도우미야. 나는 코딩을 전혀 모르는 왕초보야. '신청 폼 만들고 슈파베이스에 저장'까지 한 번에 한 단계씩만 안내해줘. 규칙: (1) 한 번에 한 단계만, 내가 "됐어" 하면 다음. (2) 쉬운 말로. (3) 누를 위치까지. (4) 캡처 보여주면 그걸 보고. 내가 준비한 것: - 슈파베이스 Project URL: [붙여넣기] - anon public key: [붙여넣기] - 신청 항목: 이름, 연락처, 관심 과정(선택), 하고 싶은 말 이 순서로: 1) 'applications' 표 만들기 — 칸(이름/연락처/관심과정/메모/신청시간)과 SQL 코드 2) 익명 방문자가 '저장만' 되게 하는 보안(RLS) — 코드와 누를 위치 3) 내 사이트에 붙일 신청 폼 HTML — 제출하면 저장되고 "신청이 접수되었습니다 :)" 4) 시험 — 한 건 넣어보고 표에서 확인 각 단계 끝에 "여기까지 됐으면 알려줘"라고 물어봐줘.
🔒 anon public 키는 공개용이라 웹에 넣어도 됩니다. service_role 키는 절대 넣지 마세요(비밀 키).
🤖 클로드 코워크로 함께 만들기 (파일·서버 직접 연결) →
