마스터 2. 내 강의실 ‘틀’ 세팅

내 웹페이지 안에 강의실(과정 카드 → 활동 목록 → 활동 페이지) 구조를 얹습니다. 남의 걸 복제하는 게 아니라, 내 홈피·내 대상자에 맞춰 뼈대를 세우고 내 브랜드 색·말투로 바꿉니다.

⏱ 약 40분📥 입력 · 1단계 아이덴티티·대상자📦 결과물 · 내 강의실 메인

💡 ‘복제’가 아니라 ‘맞춤’입니다. 잘 만든 강의실의 뼈대(구조)만 가져오고, 이름·색·환영 문구·과정 목록은 1단계에서 정한 나와 내 대상자에 맞춰 바꿉니다.
사전 진단1 정체성·대상2 강의실 세팅3 과정·활동4 안전 잠금5 교수법6 모집·수익화7 검색 노출8 마케팅 넓히기
1강의실은 딱 3층 구조

이 틀만 이해하면 뭐든 얹을 수 있어요.

  • 1층 · 강의실 메인 — 내가 여는 과정들을 카드로 보여주는 입구
  • 2층 · 과정 — 과정 하나를 열면 그 안에 '활동 목록'
  • 3층 · 활동 페이지 — 수강생이 실제로 따라 하는 페이지(프롬프트·통과기준·강사팁). 지금 보는 이 페이지가 3층입니다.
🔑 2단계는 1층(메인)을 세우고, 3단계에서 2·3층(과정·활동)을 채웁니다.
2내 강의실 메인 만들기

클로드에게 내 강의실 입구(과정 목록 페이지)를 만들어 달라고 합니다.

내 웹페이지 안에 '강의실' 메인 페이지를 하나 만들어줘. 초보도 나중에 쉽게 고칠 수 있게. [내 정보] - 내 아이덴티티 한 문장: (1단계 결과 붙여넣기) - 내 대상자: (1단계 대상자 카드 요약) - 강의실 이름 후보: (예: OOO의 컬러 강의실) 만들 것: - 상단에 강의실 이름 + 한 줄 환영 문구 (내 대상자에게 말 거는 말투) - 내가 여는 '과정'을 카드로 나열 (과정명·한 줄 소개·입장 버튼). 지금은 1개만 있어도 됨 - 각 카드에 '자료 받기'와 '신청하기' 버튼 자리 - 모바일에서 한 손으로 보기 좋게, 색은 아래 내 브랜드 색 - 내 브랜드 색(메인): (내 로고/대표 색 HEX 또는 '핑크 계열'처럼 말로) 결과는 하나의 HTML 파일로, 어디를 고치면 과정명·문구가 바뀌는지 주석으로 알려줘.
3내 브랜드로 커스터마이즈

뼈대는 같아도 느낌은 나답게. 색·말투·첫인상을 통일합니다.

방금 만든 강의실을 내 브랜드로 통일해줘. - 메인 색: (내 색 HEX/설명) — 버튼·강조에 일관되게 - 말투: (예: 다정한 반말 / 정중한 존댓말) 통일 - 첫 화면에서 '누구를 위한 강의실인지' 3초 안에 느껴지게 문구 다듬기 - 내 사진이나 로고를 넣을 자리도 표시 바꾼 부분을 '무엇을 왜 바꿨는지' 3줄로 요약해줘.
4저장하고 자리 잡기

완성한 강의실 파일을 내 사이트에 올릴 위치를 정합니다. (예: /강의/ 폴더)

💡 실제 공개(배포)는 4단계 '안전 잠금'까지 끝낸 뒤에 해도 됩니다. 지금은 파일을 만들어 두는 것까지.
🤖 클로드에서 바로 이어 하기 →
📦 결과물 — 내 강의실 메인 페이지(과정 카드 1개+)
➡ 다음 3단계에서 과정 안 '활동 페이지'를 채웁니다.
🎤 강사 팁 — 수강생이 처음부터 과정을 여러 개 만들려다 지칩니다. 과정 1개, 활동 1개만 먼저 완성하게 하세요. '완성 경험' 한 번이 끝까지 가는 힘이 됩니다.
