활동 8. 나만의 주소(도메인) 만들기 · 연결

mysite.com 처럼 나만의 인터넷 주소를 사서 내 웹페이지에 연결하는 마지막 단계입니다. 명함·SNS에 넣기 좋은 짧은 주소를 만들어 보세요.

도메인이 뭔가요?

도메인은 인터넷 주소(예: pbscolor.com)입니다. 배포하면 긴 임시 주소가 생기는데, 도메인을 사면 짧고 예쁜 나만의 주소로 바꿀 수 있어요. 보통 1년 단위로 결제합니다.

1) 도메인 구입 (원하는 곳 한 곳)

원하는 주소가 비어 있는지 검색하고 구입하세요.

  • 원하는 주소 검색 (예: mycolor.com, 내이름.kr)
  • 비어 있으면 구입(연 결제)
  • 결제하면 내 계정에 등록됩니다.
🟦 가비아(한국·한글) 열기 →🟧 Namecheap(해외·저렴) 열기 →
💡 .com이 가장 무난합니다. 한글 브랜드면 .kr / .co.kr 도 좋아요.
2) 배포한 곳에 연결

활동 4에서 배포한 곳(Netlify/Vercel)에 산 도메인을 연결합니다.

  • 배포한 사이트 설정에서 Domains(도메인) 메뉴로 이동
  • 산 도메인 입력해 추가(Add)
  • 안내되는 DNS 값을 구입처(가비아 등)에 입력
  • 보통 몇 시간~하루 안에 새 주소로 접속됩니다.
1Claude(클로드)에게 도메인 연결 맡기기
내가 산 도메인을 내 웹페이지에 연결하려고 해. 나 대신 처음부터 끝까지 이끌어줘.
- 도메인 구입처: [가비아 / Namecheap 등]
- 배포한 곳: [Netlify / Vercel 등]
어디에 무엇을 입력하는지 화면 순서대로 알려주고, DNS 설정값도 정확히 짚어줘.
중간에 헷갈리는 부분이나 실수하기 쉬운 곳은 미리 경고해줘. 막히면 "이 화면인데 어떻게 해?"라고 물을게.
💡 DNS 연결이 어렵게 느껴지면 구입처 고객센터(가비아 1544-4370 등)나 강사에게 문의하세요. 한 번만 설정하면 계속 쓸 수 있습니다. 🎉 여기까지 하면 나만의 웹페이지 완성!
