신청 제작 1. 수강생 모집·신청 페이지 만들기

신청0에서 AI가 만들어 준 제목·메인 문구·항목표를 그대로 붙여넣으면, 모집 페이지와 신청 폼이 만들어집니다. 새로 쓸 것 없이 붙여넣기만 하면 돼요.

⏱ 약 30분📥 입력 · 신청0 결과(제목·메인 문구·항목표)📦 결과물 · 모집 랜딩 + 저장되는 신청 폼

🧩 여기서는 '글쓰기'가 아니라 '붙여넣고 만들기'입니다. 신청0에서 나온 문구가 재료예요. ① 그 재료로 모집 페이지+신청 폼을 만들고, ② 제출하면 구글시트/Supabase에 저장되게 연결합니다.

1모집 페이지 + 신청 폼, 한 번에 만들기

신청0 결과를 그대로 붙여넣기만 하면 됩니다. AI가 소개·일정·강사·FAQ·신청 폼이 들어간 한 페이지를 만들어 줍니다.

너는 웹 페이지 제작 도우미야. 내 강의 '모집 페이지 + 수강 신청 폼'을 한 페이지로 만들어줘. 나는 코딩을 몰라. 아래는 앞 활동(신청0)에서 AI가 만들어 준 재료야 — 그대로 붙여넣을게. 이걸 재료로 만들어줘. [붙여넣기 — 신청0 결과] · 강의 제목: · 메인 문구(헤드라인 + 소개): · 대상 / 끝나면 얻는 것: · 일정·시간·장소·비용: · 신청서 항목표(필수/선택): · 개인정보 수집·이용 동의 문구: · 신청 완료 안내 문구: [페이지 구성 — 이 순서로] 1) 첫 화면(히어로): 제목 + 메인 문구 + '신청하기' 버튼 2) "이런 분께" — 대상 3가지 (공감되게) 3) "끝나면 얻는 것" — 3가지 4) 일정·장소·정원·비용·환불 안내(표) 5) 강사 소개 + 신뢰 요소(경력/후기) 6) 자주 묻는 질문 3개 7) 신청 폼: 위 '항목표' 그대로 + 동의 체크(동의해야 제출) + 제출하면 완료 안내 8) 맨 아래 '신청하기' 버튼 한 번 더 [스타일] 모바일에서 잘 보이게, 버튼은 눈에 띄게, 글은 짧고 쉽게. 먼저 내 상황(클로드로 새로 만드는 페이지인지 / 기존 홈페이지에 붙일지)을 물어보고 그에 맞게 만들어줘.
🎯 신청 버튼은 최소 2번 — 맨 위(히어로)와 맨 아래에. 마음먹었을 때 바로 누를 수 있어야 신청합니다.
2제출되면 저장되게 연결하기

신청이 사라지지 않고 저장돼야 합니다. 두 가지 길 중 내 상황에 맞는 것을 AI가 추천해 줍니다.

  • 가장 쉬운 길 · 구글폼 → 구글시트 — 5분·무료, 응답이 시트에 자동 저장(엑셀로 바로 열림). 초보 추천.
  • 사이트 안에서 · Supabase — 내 페이지 디자인 그대로 받아 DB에 저장. 자동화·확장에 유리.
방금 만든 신청 폼을 '제출하면 저장'되게 연결해줘. 나는 초보라 클릭 순서로 알려줘. [먼저 나에게 물어봐줘] 저장을 어디에 할지 — 아래 둘 중 내 상황에 맞게 추천해서 그대로 세팅 안내 (A) 구글폼 → 구글시트 : 가장 쉬움·무료 · 구글폼 만드는 클릭 순서 → 내 '신청하기' 버튼에 연결 → 응답이 시트에 쌓이는지 확인 (B) Supabase 테이블 : 내 페이지 안에서 바로 받기 · 테이블 만들기 → 제출 저장 코드 → 저장 확인 [공통으로 꼭] - 신청서 항목(이름·연락처·[선택])과 '개인정보 동의 체크'(동의 안 하면 제출 불가) 그대로 - 제출 후 "신청이 접수됐습니다. 확인 후 연락드릴게요" 안내 화면 - 마지막에 '테스트 신청'을 한 번 해서 시트/DB에 저장되는지 눈으로 확인하는 것까지 초보도 따라 하게 하나씩 순서대로.
⚠️ 동의 없이는 제출 불가로 만들고, 완료 화면에 "확인 후 연락드립니다"를 넣으세요. 신청자가 접수됐는지 몰라 불안해하지 않게.
