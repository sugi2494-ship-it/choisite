신청 제작 1. 수강생 모집·신청 페이지 만들기

특강을 알리는 모집 페이지와, 그 안에서 바로 신청을 받는 폼을 만듭니다. 제출하면 데이터가 어딘가에 저장되는 것까지가 목표예요.

⏱ 약 30분📥 입력 · 활동 0의 한 문장·항목표📦 결과물 · 모집 랜딩 + 저장되는 신청 폼

📌 여기서 만드는 것: ① 특강을 소개하는 모집 페이지(랜딩), ② 그 안의 신청 폼, ③ 제출 시 구글시트 또는 Supabase에 자동 저장. 관리자 화면·알림은 다음 활동에서.
0 준비·설계1 모집·신청 페이지2 관리자·실시간 알림3 안전 로그인·문자·엑셀4 5분 복제
1모집 페이지(랜딩) 만들기

"이 특강이 뭐고, 나에게 왜 필요하고, 어떻게 신청하는지"가 한 화면에 보이게 합니다.

너는 웹 페이지 제작 도우미야. 내 2~3시간 특강 '모집 페이지(랜딩)'를 한 페이지로 만들어줘. [구성 순서] 1) 첫 화면(히어로): 특강 제목 + 한 문장 소개 + '신청하기' 버튼 2) 이런 분께: 대상 3가지 (공감 문구) 3) 끝나면 얻는 것: 결과물/변화 3가지 4) 일정·장소(온/오프)·정원·가격·환불 안내(표) 5) 강사 소개(나) 한 단락 + 신뢰 요소(경력/후기) 6) 자주 묻는 질문 3개 7) 맨 아래 다시 '신청하기' 버튼 [스타일] 모바일에서 잘 보이게, 버튼은 눈에 띄게, 글은 짧고 쉽게. 내 특강 한 문장을 붙여넣을 테니 그에 맞춰 만들어줘.
🎯 신청 버튼은 최소 2번 — 맨 위(히어로)와 맨 아래에. 사람들은 스크롤하다 마음먹으면 바로 누를 수 있어야 신청합니다.
2신청 폼 붙이고 저장되게 하기

제출한 신청이 사라지지 않고 저장돼야 합니다. 두 가지 길 중 상황에 맞게 고르세요.

  • 가장 쉬운 길 · 구글폼→구글시트 — 5분이면 완성, 무료, 응답이 구글시트에 자동 저장(엑셀로 바로 열림). 초보 추천.
  • 사이트 안에서 · Supabase — 내 페이지 디자인 그대로 폼을 넣고 DB에 저장. 확장·자동화에 유리(홈페이지와 같은 스택).
너는 웹 개발 도우미야. 내 모집 페이지에 '신청 폼'을 붙이고, 제출하면 저장되게 해줘. - 받을 항목: (활동 0에서 정한 항목표 그대로) 이름 / 연락처 / [선택] / 개인정보 수집·이용 동의(체크) - 저장 위치: 내 상황을 물어보고 아래 중 추천해서 그대로 세팅 안내 · (A) 구글폼 → 구글시트 : 만드는 클릭 순서, 폼을 내 '신청하기' 버튼에 연결하는 법 · (B) Supabase 테이블 : 테이블 만들기 + 폼 제출 코드 + 저장 확인 - 동의 체크 안 하면 제출 안 되게, 제출 후 "신청이 접수됐습니다" 안내 화면 - 개인정보는 꼭 필요한 것만 초보도 따라 하게 클릭/코드 순서로 하나씩 알려줘.
⚠️ 동의 없이는 제출 불가로 만들고, 신청 완료 화면에 "곧 확인 후 연락드립니다"를 넣으세요. 신청자가 접수됐는지 몰라 불안해하지 않게.
