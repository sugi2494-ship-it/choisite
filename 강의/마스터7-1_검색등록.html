마스터 7-1. 네이버·구글에 내 사이트 등록

검색에 뜨려면 먼저 “내 사이트가 여기 있어요”라고 검색엔진에 알려야 합니다. 네이버·구글의 무료 도구에 등록하고 사이트맵을 제출합니다. 한 번만 하면 되는 기초 작업.

⏱ 약 30분📥 입력 · 내 사이트 주소·사이트맵📦 결과물 · 검색엔진 등록

💡 등록을 안 하면 검색엔진이 내 사이트를 늦게 알거나 못 찾습니다. 한 번만 해두면 되는 기초예요.

1왜 등록? + 준비물

검색에 뜨려면 먼저 검색엔진에 “내 사이트 여기 있어요”라고 알려야 합니다. 한 번만 하면 됩니다.

  • 내 사이트 주소 (예: 내이름.com)
  • 사이트맵 주소 — 보통 내주소/sitemap.xml (내 페이지 목록 '지도')
  • 소유확인용으로 내 사이트를 조금 수정할 수 있어야 함(메타태그 한 줄 넣기 등)
💡 사이트맵(sitemap.xml)·robots.txt가 없으면 AI에게 "내 사이트 sitemap.xml과 robots.txt를 만들어줘"라고 요청하세요. (이 강의실처럼 만든 사이트는 대개 이미 있습니다.)
2🔵 구글에 등록 — 구글 서치콘솔

전 세계 검색의 기본. 무료입니다.

  1. 아래 버튼 → 속성 추가 → URL 접두어에 내 사이트 주소
  2. 소유확인 — 'HTML 태그'(메타태그 한 줄) 방식이 가장 쉬움 → 내 사이트 <head>에 붙이기
  3. 왼쪽 Sitemaps → sitemap.xml 입력 후 제출
🔵 구글 서치콘솔 열기 →
너는 나를 1:1로 돕는 도우미야. 나는 왕초보야. 구글 서치콘솔에 내 사이트를 등록하고 '소유확인 → 사이트맵 제출'까지 한 단계씩 안내해줘. - 내 사이트 주소: [붙여넣기] - 사이트맵 주소: [내주소/sitemap.xml] 규칙: 한 번에 한 단계, 쉬운 말, 누를 위치까지. 소유확인은 가장 쉬운 방법(HTML 메타태그)으로, 그 태그를 내 사이트 어디에 어떻게 넣는지까지 알려줘. (내가 캡처 보여주면 그걸 보고) 각 단계 끝에 "여기까지 됐으면 알려줘".
3🟢 네이버에 등록 — 네이버 서치어드바이저

국내 검색은 네이버가 큽니다. 방식은 구글과 비슷.

  1. 아래 버튼 → 웹마스터 도구 → 사이트 등록에 내 주소
  2. 소유확인(HTML 태그/파일) → 내 사이트에 넣기
  3. 요청 → 사이트맵 제출에 sitemap.xml, 웹페이지 수집도 요청
🟢 네이버 서치어드바이저 열기 →
너는 나를 1:1로 돕는 도우미야. 나는 왕초보야. 네이버 서치어드바이저(웹마스터도구)에 내 사이트를 등록하고 소유확인·사이트맵 제출·수집요청까지 한 단계씩 안내해줘. - 내 사이트 주소: [붙여넣기] - 사이트맵 주소: [내주소/sitemap.xml] 한 번에 한 단계, 쉬운 말, 누를 위치까지. 각 단계 끝에 "여기까지 됐으면 알려줘".
🤖 클로드 코워크로 함께 만들기 (파일·서버 직접 연결) →
🌱 등록해도 검색에 실제로 뜨기까지 며칠~몇 주 걸립니다. 조급해하지 말고, 그 사이 6단계 홍보로 사람을 모으세요.
📦 결과물 — 구글·네이버에 내 사이트 등록 + 사이트맵 제출

🎤 강사 팁 — 소유확인에서 대부분 막힙니다. 메타태그 방식을 기본으로 가르치고, 태그 넣는 위치(<head>)를 화면으로 보여주세요. 코워크로 하면 파일을 직접 넣어줘 더 쉽습니다.
