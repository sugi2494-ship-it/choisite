활동 1. 나만의 도메인 만들기 & 연결

내 사이트는 이미 배포돼 있죠(넷플리 기본주소 xxxxxx.netlify.app). 이번 활동에서는 그 사이트에 내 브랜드 주소(예: mycolor.com)를 만들어 연결하고, 자물쇠(https)까지 켭니다.

✅ 배포는 이미 끝냈습니다. (기본 과정 「AI 웹페이지 제작 · 활동 4. 배포하기」에서 완료) — 이 활동은 도메인만 집중해서 다룹니다.
1도메인 이름 정하기

주소는 한 번 정하면 오래 씁니다. 아래 기준으로 신중히 골라요.

  • 짧고 외우기 쉽게 — 발음했을 때 바로 받아 적을 수 있게
  • 내 이름·브랜드가 들어가게 — 예: choihaesuk, pbscolor
  • 하이픈(-)·숫자는 되도록 피하기 — 헷갈립니다
  • 끝자리(.com / .kr / .co.kr) — 가장 무난한 건 .com, 국내 느낌은 .kr

💬 안 정해질 때 — 추천받기 프롬프트

내 브랜드에 어울리는 도메인(웹사이트 주소) 이름을 추천해줘. - 내가 하는 일: - 브랜드/활동명: - 원하는 느낌(예: 깔끔한/전문적인/기억하기 쉬운): 조건: 1) 짧고 외우기 쉽게, 영어 스펠링도 알려줘 2) .com / .kr / .co.kr 중 뭐가 좋은지 이유와 함께 3) 후보 8개를 표로: 도메인 | 읽는 법 | 추천 이유 4) 이미 많이 쓰일 것 같은 건 표시해줘
2도메인 구입하기

국내에서 많이 쓰는 곳: 가비아 · 후이즈 · 카페24. (연 1~2만원대)

  • 가비아(gabia.com) 예시 — 검색창에 원하는 주소 입력 → 사용 가능하면 신청하기
  • 기간(보통 1년) 선택 → 결제 → 내 계정에 도메인 등록 완료
  • 구입 후 「My가비아 → 도메인 관리」 화면을 열어둡니다 (다음 단계에서 씀)
💡 도메인은 구입한 순간엔 아직 내 사이트와 연결 안 됨. 3단계에서 연결해야 진짜 내 주소가 됩니다.
3넷플리에 도메인 연결하기

넷플리에 "이 주소를 내 사이트에 붙여줘"라고 알려주는 단계입니다.

  • 넷플리 내 사이트 → Domain management → Add a domain
  • 구입한 도메인 입력(예: mycolor.com) → Verify → Add domain

연결 방법은 둘 중 하나

🟢 방법 A. 네임서버를 넷플리로 (권장·쉬움) 넷플리가 알려주는 네임서버 주소 4개를, 가비아 「도메인 관리 → 네임서버 설정」에 그대로 입력. 이후 DNS는 넷플리가 알아서 관리 → 편합니다.
🔵 방법 B. DNS 레코드 직접 입력 가비아 「DNS 관리」에서 넷플리가 안내한 A 레코드(뿌리주소용)와 CNAME(www용)을 입력. 기존 메일 등 다른 설정을 유지하고 싶을 때.
⏳ 연결은 보통 몇 분~몇 시간(길면 하루) 걸립니다. 바로 안 돼도 정상이니 기다려요.
4자물쇠(https) 활성화

연결이 되면 넷플리가 보안 인증서를 자동으로 발급합니다.

  • 넷플리 Domain management → HTTPS 에서 「Verify DNS configuration」 → 자동 발급
  • 발급되면 Force HTTPS 켜기 — 항상 자물쇠(https)로 열리게
  • 주소창에 🔒 자물쇠가 보이면 완료
5최종 점검

🛠 도메인이 안 붙을 때 — 문제 해결 프롬프트

넷플리에 도메인 연결이 안 돼서 도움이 필요해. 초보도 알 수 있게 쉽게 알려줘. - 도메인 구입처: (가비아/후이즈 등) - 내 도메인: - 넷플리 기본주소: (xxxxxx.netlify.app) - 화면에 뜬 메시지(있으면 그대로 붙여넣기): 원하는 것: 1) 지금 문제의 원인을 쉬운 말로 2) 가비아(또는 구입처)와 넷플리에서 각각 눌러야 할 곳을 순서대로 3) 얼마나 기다려야 하는지, 그래도 안 되면 무엇을 확인하는지
