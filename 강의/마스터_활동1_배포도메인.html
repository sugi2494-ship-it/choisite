활동 1. 넷플리 배포 & 나만의 도메인

사전활동에서 점검한 내 사이트를, 이제 누구나 들어올 수 있는 정식 주소로 완성합니다. 넷플리(Netlify)에 올리고 → 주소를 정리하고 → 나만의 도메인을 연결해 → 자물쇠(https)까지 켭니다.

1넷플리에 내 사이트 올리기

가장 쉬운 방법은 "드래그 배포"입니다.

  1. app.netlify.com 로그인 → Add new site → Deploy manually
  2. 내 사이트 폴더(HTML 파일들)를 드래그해서 올리기
  3. 몇 초 뒤 xxxxxx.netlify.app 주소가 생기면 성공 — 눌러서 잘 열리는지 확인
2사이트 주소 정리하기

넷플리 기본 주소(랜덤 글자)를 내 이름으로 바꿉니다.

  1. 넷플리 사이트 → Site configuration → Change site name
  2. 기억하기 쉬운 이름으로 (예: choi-color.netlify.app)
3나만의 도메인 연결 (추천)

내 브랜드 주소(예: mycolor.com)가 있으면 훨씬 전문적으로 보입니다.

  1. 도메인 구입 — 가비아·후이즈 등에서 원하는 주소 구매(연 1~2만원대)
  2. 넷플리 → Domain management → Add a domain → 내 도메인 입력
  3. 안내에 따라 DNS 연결 — 도메인 구입처에서 네임서버를 넷플리 것으로 바꾸거나, 안내된 레코드 입력
  4. 연결되면 넷플리가 https(자물쇠)를 자동으로 켜줍니다 (몇 분~몇 시간 소요)

💬 도메인 이름이 안 정해질 때 — 아래 프롬프트로 추천받기

내 브랜드에 어울리는 도메인(웹사이트 주소) 이름을 추천해줘. - 내가 하는 일: - 브랜드/활동명: - 원하는 느낌(예: 깔끔한/전문적인/기억하기 쉬운): 조건: 1) 짧고 외우기 쉽게, 영어 스펠링도 알려줘 2) .com / .kr / .co.kr 중 뭐가 좋은지 이유와 함께 3) 후보 8개를 표로: 도메인 | 읽는 법 | 추천 이유 4) 이미 많이 쓰일 것 같은 건 표시해줘
4최종 확인

🛠 배포·도메인이 안 될 때 — 문제 해결 프롬프트

넷플리 배포/도메인 연결이 안 돼서 도움이 필요해. 초보도 알 수 있게 쉽게 알려줘. - 상황(무엇을 하다가 막혔는지): - 화면에 뜬 메시지(있으면 그대로 붙여넣기): - 내 주소: (netlify.app 주소 / 연결하려는 도메인) 원하는 것: 1) 지금 문제의 원인을 쉬운 말로 2) 순서대로 따라할 해결 단계 3) 그래도 안 되면 어디를 확인해야 하는지
💡 도메인은 없어도 다음 활동으로 넘어갈 수 있어요. 넷플리 기본 주소(xxxxxx.netlify.app)로도 검색등록까지 다 됩니다. 나중에 도메인만 연결하면 됩니다.
