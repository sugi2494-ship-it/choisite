활동 3. 퀄리티 올리기 · 관리자 페이지 만들기

초안을 한 단계 더 완성도 있게 다듬고, 내가 직접 내용을 바꿀 수 있는 관리자 페이지까지 붙이는 단계입니다. 아래 프롬프트를 복사해 이어서 붙여넣으세요.

A. 퀄리티(완성도) 올리기
1디자인 고급스럽게 다듬기
전체 디자인을 더 세련되고 신뢰감 있게 다듬어줘.
- 여백을 넉넉하게, 글자 크기·굵기의 위계를 분명하게
- 포인트 색은 [내 브랜드색]만 절제해서 사용
- 촌스럽지 않고 고급스럽고 단정한 느낌으로.
2문구(카피) 매력적으로 다듬기
각 섹션의 문구를 더 매력적이고 설득력 있게 다듬어줘.
전문성이 느껴지되 따뜻하고, 읽기 쉬운 한국어로.
특히 첫 화면 한 줄 소개와 강의 소개 문구를 눈길이 가게 고쳐줘.
3모바일 화면 점검
휴대폰 화면에서 글자·버튼·이미지가 잘리거나 너무 작지 않은지 점검하고 고쳐줘.
버튼은 손가락으로 누르기 좋게, 사진은 화면 폭에 맞게.
4신뢰 요소 강조
후기·경력·자격증·방송 출연·교육 인원 같은 신뢰 요소를 눈에 띄게 배치해줘.
숫자가 있으면(예: 강의 10년, 수료 500명) 크게 강조해줘.
B. 관리자 페이지 만들기 (내가 직접 내용 수정)
5간단 관리자 페이지 만들기
이 웹페이지의 텍스트(소개·강의·연락처)를 내가 코드를 안 건드리고 바꿀 수 있는 간단한 관리자 페이지를 만들어줘.
- 비밀번호를 입력해야 들어갈 수 있게
- 수정한 내용은 브라우저에 저장되어 새로고침해도 유지되게
- 초보자도 쓸 수 있게 입력칸을 크고 알기 쉽게.
6문의 내용 저장·확인
문의 폼에 들어온 내용(이름·연락처·문의)을 관리자 페이지에서 목록으로 볼 수 있게 해줘.
무료로 할 수 있는 방법(예: Supabase, 구글 시트, 폼 서비스)으로,
설정 방법을 초보자용으로 단계별로 알려줘.
7사진·로고 교체 기능
관리자 페이지에서 프로필 사진·강의 사진·로고를 파일 선택으로 교체할 수 있게 해줘.
바꾸면 웹페이지에 바로 반영되게.
