신청 저장 2. 신청 저장 연결

앞에서 만든 신청 폼을 제출하면 실제로 저장되게 연결합니다. 두 방법이 있어요 — 구글시트(가장 쉬움) 또는 Supabase(사이트와 같은 스택). 둘 중 하나만 골라서 하면 됩니다.

⏱ 약 25분📥 입력 · 신청1의 신청 폼📦 결과물 · 제출 → 자동 저장 + 저장 확인

💾 둘 중 하나만 고르세요. 처음이거나 무료·쉬운 게 좋다면 A. 구글시트, 내 사이트 안에서 받고 확장하고 싶다면 B. Supabase. 각각 별도 프롬프트가 준비돼 있습니다.
0 준비·설계1 모집·신청 페이지2 저장 연결3 관리자·알림4 안전·엑셀5 5분 복제
A. 구글시트 (추천·초보)5분·무료. 신청이 구글시트에 자동으로 쌓이고 엑셀로 바로 열림. 코딩 거의 없음.
B. Supabase (확장)내 페이지 안에서 바로 받아 DB에 저장. 관리자 페이지·자동화에 유리(사이트와 같은 스택).
A구글시트로 저장하기 (가장 쉬움)

신청 내용이 구글시트에 한 줄씩 자동으로 쌓이게 합니다. 무료이고, 시트는 곧 엑셀이라 명단 관리가 편해요.

내 강의 신청 폼을 '구글시트에 자동 저장'되게 연결하고 싶어. 나는 초보라 클릭 순서로 알려줘. [내 상황] · 신청 폼은 (신청1에서 만든 웹페이지 안의 폼 / 아직 없음) 중 : (여기 적기) · 받는 항목: 이름 / 연락처 / (선택) / 개인정보 동의 [두 가지 길 중 내게 맞는 걸 추천하고 그대로 안내해줘] (1) 가장 쉬움 — '구글폼'으로 만들어 구글시트에 자동 저장 · 구글폼 만드는 순서 → 항목·동의 체크 넣기 → 응답이 구글시트에 쌓이는지 확인 · 내 모집 페이지의 '신청하기' 버튼을 이 구글폼으로 연결하는 법 (2) 내 웹페이지 폼 그대로 쓰고 싶다 — '구글 앱스스크립트(웹앱)'로 시트에 저장 · 스프레드시트 만들기 → 앱스스크립트 붙여넣기 → 웹앱으로 '배포'해서 주소(URL) 받기 · 그 주소를 내 폼 제출에 연결(제출하면 시트에 한 줄 추가) [공통] · 제출 후 "신청이 접수됐습니다. 확인 후 연락드릴게요" 안내 · 마지막에 '테스트 신청'을 한 번 해서 시트에 저장되는지 눈으로 확인 어려운 말 없이, 클릭 순서로 하나씩.
🟢 처음이라면 이걸 추천 — 구글폼→구글시트가 제일 빠르고 확실합니다. "응답 → 스프레드시트"만 연결하면 신청이 자동으로 쌓여요.
BSupabase로 저장하기 (사이트 안에서)

내 페이지 디자인 그대로 신청을 받아 DB(표)에 저장합니다. 다음 활동의 관리자 페이지·자동화와도 잘 이어집니다.

내 강의 신청 폼을 'Supabase 데이터베이스에 저장'되게 연결하고 싶어. 나는 초보라 클릭·코드 순서로 하나씩 알려줘. [내 상황] · 신청 폼은 신청1에서 만든 내 웹페이지 안에 있어 · 받는 항목: 이름 / 연락처 / (선택) / 개인정보 동의 / (교육명·접수일시는 자동) [해줘] 1) Supabase 프로젝트·테이블 만들기 — 신청을 담을 테이블(applications 등)과 컬럼(이름·연락처·선택·동의·교육명·접수일시) 2) 내 폼 제출 코드 — 제출하면 이 테이블에 한 줄 저장되게 (공개키/anon key 사용법 포함) 3) 동의 체크 안 하면 제출 안 되게, 제출 후 "접수됐습니다" 안내 4) 보안 기본 — 아무나 남의 신청을 '읽지'는 못하게(RLS). 저장(insert)만 허용 ※ 관리자 화면에서 읽는 '안전한 방법'은 다음 활동(안전 로그인)에서 다룬다고만 알려줘 5) 마지막에 '테스트 신청'을 해서 Supabase 테이블에 저장되는지 확인 내 사이트가 (클로드로 만든 페이지 / Netlify / 기타)인지 물어보고 그에 맞게 단계별로.
⚠️ 키(key) 조심 — '공개(anon) 키'만 페이지에 쓰고, 비밀 키(service key)는 절대 페이지 코드에 넣지 마세요. 그리고 신청 데이터는 아무나 읽지 못하게(RLS) 막아야 합니다. 관리자만 읽는 안전한 방법은 4단계에서 배웁니다.
🤖 클로드에서 바로 이어 하기 →
📦 이 활동의 결과물 — 제출하면 실제로 저장되는 신청 시스템(구글시트 또는 Supabase). 이제 신청이 쌓이기 시작합니다. 다음은 내가 바로 보고 알림 받는 관리자 화면.
🎤 강사 팁 (강사 전용) — 초보 반은 A(구글시트)로 통일하면 100% 성공합니다. Supabase(B)는 관리자 페이지·자동화까지 갈 여유 반에서만 권하세요. 어느 쪽이든 "테스트 신청 → 저장 눈으로 확인"을 반드시 시켜야, 다음 관리자 단계가 매끄럽습니다.
