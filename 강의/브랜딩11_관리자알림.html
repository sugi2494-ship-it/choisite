브랜딩 관리 11. 관리자 페이지 + 실시간 알림

문의를 놓치지 않게 — 문의 폼 → 관리자 페이지 → 실시간 알림(카톡/문자)까지. 비번은 코드에 넣지 않고 안전하게.

0 단계
먼저

문의를 놓치지 않으려면

받는 곳 + 알림 + 안전

세 가지가 필요해요
① 문의 받는 폼 → ② 관리자 페이지(들어온 문의 확인) → ③ 실시간 알림(새 문의 오면 카톡/문자).
비밀번호를 코드에 그냥 넣지 마세요(8808식 금지). 안전하게 서버검증으로.
STEP 1

문의 접수 + 관리자 페이지

들어온 문의를 한곳에서

저장은 2가지 중 택1
🟢 구글 시트(쉬움) — 문의가 시트에 쌓임
⚫ Supabase(고급) — 관리자 페이지에서 바로 관리
초보는 구글 시트부터. 익숙해지면 Supabase로.
★ 접수문의 폼 + 관리자 페이지 만들기▾
내 웹페이지에 '문의하기' 폼(이름·연락처·문의내용)을 만들고, 들어온 문의를 내가 볼 수 있는 관리자 페이지도 만들어줘. - 저장은 [구글 시트 / Supabase] 중 [구글 시트]로 할게. 연결 방법을 한 단계씩 쉽게. - 관리자 페이지는 비밀번호를 코드에 그냥 넣지 말고 안전하게(서버검증) 잠가줘. - 개인정보는 꼭 필요한 것만 받고, 수집·이용 동의 문구도 넣어줘.

[ ] 안에서 쉬운 쪽(구글 시트)을 고르세요. Supabase는 다음에 도전.

STEP 2

새 문의 실시간 알림

폰으로 바로 알림 오게

★ 알림새 문의 카톡/문자 알림 연결▾
새 문의가 들어오면 내 휴대폰으로 바로 알림이 오게 해줘. - [카카오톡 알림 / 문자(SMS) / 이메일] 중 [카카오톡]으로 받고 싶어. - 초보도 할 수 있는 가장 쉬운 방법(예: 무료 자동화 도구)으로, 한 단계씩 안내해줘. - 문의 내용 요약(이름·연락처·내용)이 알림에 담기게.

문자·알림톡은 발송비·사전승인이 필요할 수 있어요 — 대표님 승인 전까지는 이메일/무료 알림으로.

STEP 3

안전·개인정보 점검

신뢰가 브랜드입니다
