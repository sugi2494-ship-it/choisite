활동 2. 나만의 강의실 + 접수·문자 구축

방문자가 실제로 보고 신청까지 하는 "기계"를 먼저 완성합니다. 이게 다 되어야 다음 활동(검색등록·모집)에서 들어온 사람이 헛걸음하지 않아요.

🏗 만드는 순서: 강의실 페이지 → 데이터 창고(슈파베이스) → 접수 폼·관리자 → 문자 알림
1내 강의실 페이지 만들기

내 사이트 안에, 과정을 소개하고 자료를 주는 "강의실"을 만듭니다.

💬 클로드에 붙여넣기
내 사이트에 '강의실' 페이지를 하나 만들어줘. - 내가 여는 강의(과정) 목록을 카드로 보여줘. (예: 과정명·한줄소개·입장 버튼) - 각 과정 안에는 '자료 받기'(파일 링크)와 '신청하기' 버튼이 있게. - 관리자만 자료를 올리고 바꿀 수 있게 비밀번호 입장으로. - 초보도 나중에 내용을 쉽게 바꿀 수 있게 만들어줘.
2데이터 창고 연결 (슈파베이스)

신청·문의 내용을 저장할 무료 창고가 필요합니다. 이 사이트도 슈파베이스를 씁니다.

  1. 아래 버튼 → Start your project로 가입(구글 계정, 1분)
  2. New Project로 프로젝트 생성(1~2분)
  3. 왼쪽 Settings → API에서 Project URL과 anon public 키 복사
🟢 슈파베이스 열기 →
💬 연결 프롬프트
내 웹페이지의 신청·문의 폼이 슈파베이스에 저장되게 연결해줘. - 내 슈파베이스 정보: URL은 [붙여넣기], anon key는 [붙여넣기] - 테이블은 applications(신청)·contacts(문의)로, 없으면 만들고 컬럼도 만들어줘. - 방문자(익명)가 저장할 수 있게 보안(RLS) 설정 방법도 초보자용으로 알려줘.
🔒 anon public 키는 웹에 넣어도 되는 공개용입니다. 하지만 service_role 키는 절대 웹페이지·프롬프트에 넣지 마세요(비밀 키).
3접수(신청) 폼 + 관리자 페이지

방문자가 신청하고, 나는 관리자 페이지에서 확인·다운로드합니다.

💬 신청 폼 만들기
방문자가 신청할 수 있는 간단한 신청 폼을 만들어줘. - 항목: 이름, 연락처, "어떤 과정에 관심 있으세요?"(선택), "하고 싶은 말"(주관식) - 제출하면 슈파베이스 applications 테이블에 저장되게 - 제출 후 "신청이 접수되었습니다 :)" 화면이 뜨게.
💬 관리자 페이지 + 엑셀 다운로드
신청·문의 결과를 보는 관리자 페이지를 만들어줘. - 비밀번호로 들어가게 - 받은 내용을 표로 보여주고, 새 접수는 맨 위에 실시간으로 뜨게(새로고침 없이) - 맨 위에 "엑셀(CSV) 다운로드" 버튼.
4신청 오면 문자(SMS) 알림

신청이 들어오면 내 휴대폰으로 바로 문자가 오게 합니다. 놓치지 않아요.

  1. 문자 발송 서비스에 가입 — 알리고 · 솔라피 등(건당 몇 원, 저렴)
  2. 발신번호 등록(본인 인증) → API 키 발급
  3. 아래 프롬프트로 클로드에게 "신청되면 문자 보내기"를 연결 요청
💬 문자 알림 연결 프롬프트
신청이 슈파베이스에 저장되면, 내 휴대폰으로 문자(SMS)가 자동으로 오게 연결해줘. - 문자 서비스: 알리고(또는 솔라피) - 받을 내 번호: [내 휴대폰번호] - 문자 내용: "[새 신청] {이름} / {연락처} / {관심과정}" - API 키를 웹페이지에 그대로 넣지 말고, 안전하게 두는 방법(슈파베이스 Edge Function 등)으로 알려줘. ※ API 키·인증·결제는 내가 직접 입력할게. 너는 어디에 넣고 어떻게 연결하는지 단계로 안내해줘.
🤖 클로드 코워크로 연결하기 →
💡 문자 세팅이 어려우면 강사(최해숙 대표)에게 "실시간 알림 연결"을 요청하세요 — PBS 자동문자(PBS_AutoSMS) 방식으로 연결해 드립니다. 우선 알림톡·텔레그램으로 시작했다가 나중에 문자로 바꿔도 됩니다.
