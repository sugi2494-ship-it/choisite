활동 4. 웹페이지 배포하기 (인터넷에 공개)

내 컴퓨터에 있는 HTML 파일을 인터넷 주소로 공개하는 단계입니다. 가장 쉬운 두 가지 방법(Netlify · Vercel)을 소개합니다. 둘 다 무료로 시작할 수 있어요.

방법 A. Netlify Drop — 가장 쉬움 (드래그 한 번)

파일을 끌어다 놓기만 하면 바로 인터넷 주소가 생깁니다. 회원가입 없이도 됩니다.

  • 아래 Netlify Drop 열기 버튼을 누르세요.
  • 내 HTML 파일(index.html)을 화면 안으로 끌어다 놓으세요.
  • 몇 초 뒤 인터넷 주소가 생깁니다 — 그 주소를 복사해 공유하면 끝!
  • 수정했으면 새 파일을 다시 끌어다 놓으면 갱신됩니다.
🟢 Netlify Drop 열기 →
💡 파일 이름은 반드시 index.html 로 저장하세요. 사진이 있으면 HTML과 같은 폴더에 함께 넣어 폴더째 끌어다 놓으면 됩니다.
방법 B. Vercel — 조금 더 전문적 (수정 관리 편함)

가입 후 파일을 올리면 주소가 생기고, 나중에 수정·관리가 편합니다.

  • 아래 Vercel 열기 버튼을 누르고 가입/로그인 하세요.
  • 내 HTML 파일(또는 폴더)을 업로드하거나 GitHub와 연결하세요.
  • Deploy(배포)를 누르면 인터넷 주소가 만들어집니다.

💡 처음이라면 방법 A(Netlify Drop)가 가장 쉽습니다. 익숙해지면 Vercel로 옮겨도 됩니다.
1배포 도우미 프롬프트
내가 만든 이 웹페이지를 Netlify에 무료로 올리려고 해.
초보자가 따라 할 수 있게, 준비물과 순서를 아주 쉽게 하나씩 알려줘.
(파일 이름은 뭐로 해야 하는지, 사진은 어떻게 같이 올리는지도 알려줘.)
2공유 미리보기 예쁘게 (선택)
내 웹페이지 주소를 카카오톡·인스타·문자로 공유할 때
제목·설명·대표 이미지가 예쁘게 미리보기로 뜨도록 메타태그(Open Graph)를 넣어줘.
대표 이미지는 내 프로필 사진으로 해줘.
