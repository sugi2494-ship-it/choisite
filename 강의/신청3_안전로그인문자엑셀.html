신청 보안 3. 안전한 로그인 + 문자·엑셀·기록

관리자 화면엔 신청자 개인정보가 있으니 반드시 안전하게 잠급니다(서버 검증). 그리고 접수 목록을 엑셀로 내려받고, 원하면 실제 문자(SMS)까지 붙입니다.

⏱ 약 30분📥 입력 · 활동 2의 관리자 페이지📦 결과물 · 안전 잠금 + 엑셀 다운로드 + (선택)문자

🔐 가장 중요한 보안 원칙: 관리자 비밀번호를 웹페이지 코드 안에 넣으면 안 됩니다(누구나 '소스 보기'로 뚫립니다). 반드시 서버에서 검증하세요. 개인정보를 다루는 만큼 이 단계가 핵심입니다.
0 준비·설계1 모집·신청 페이지2 관리자·실시간 알림3 안전 로그인·문자·엑셀4 5분 복제
1안전한 로그인 — 서버 검증 (핵심)

틀린 비번으로는 신청 데이터가 아예 안 내려오게 만드는 것이 목표입니다.

⚠️ 이렇게 하면 안 됩니다 — 페이지 코드에 if(비번==="1234")처럼 넣기. 누구나 브라우저 '소스 보기'로 비번을 읽고 들어옵니다. 가장 흔한 실수예요.
내 관리자 페이지 로그인을 '서버 검증' 방식으로 안전하게 만들어줘. (클라이언트 비번 금지) [해줘] 1) 비밀번호는 페이지 코드가 아니라 '서버(예: Supabase Edge Function)의 환경변수/시크릿'에 저장 2) 로그인 시 입력한 비번을 서버로 보내 검증하고, 맞을 때만 데이터를 내려주기 (틀리면 401, 데이터는 애초에 브라우저로 안 내려오게) 3) 신청 데이터도 아무나 못 읽게 — DB 접근 권한(RLS/서비스키)로 서버에서만 읽기 4) 왜 이 방식이 안전한지 한 줄 설명 내 사이트가 (Netlify + Supabase / 구글시트 / 다른 스택)인지 물어보고 그에 맞게 단계별로 안내해줘.
✅ 이 정도면 통과 — 관리자 비번이 페이지 소스에 없고(서버에만), 틀린 비번으로는 신청 데이터가 아예 안 보이면 안전합니다.
2엑셀 다운로드 & 기록 남기기

접수 명단을 엑셀로 내려받아 출석부·정산에 쓰고, 처리 기록(상태·메모)을 남깁니다.

  • 구글시트로 저장했다면 — 이미 시트가 곧 엑셀입니다(파일 → 다운로드 → Excel). 관리자 페이지에 '시트 열기' 버튼만 달면 끝.
  • Supabase로 저장했다면 — 관리자 페이지에 '엑셀(CSV) 다운로드' 버튼을 붙여 현재 목록을 내려받게 합니다.
내 관리자 페이지에서 신청 명단을 엑셀로 내려받고, 처리 기록을 남기게 해줘. [해줘] 1) '엑셀 다운로드' 버튼: 현재 화면의 신청 목록(필터 적용된 것)을 CSV/엑셀로 저장 - 컬럼: 이름·연락처·신청항목·상태·메모·접수일시 2) 상태 변경(대기→연락함→확정)과 메모가 저장되고, '누가 언제 바꿨는지' 기록이 남게 3) 개인정보라 다운로드 파일 취급 주의 문구 한 줄(외부 공유·방치 금지) 내 저장 방식(구글시트/Supabase)에 맞게 버튼과 코드까지 만들어줘.
⚠️ 다운로드한 엑셀도 개인정보입니다. 아무 폴더에 방치하거나 외부에 공유하지 말고, 특강이 끝나 목적이 사라지면 보관 기준에 따라 정리하세요.
3(심화·선택) 실제 휴대폰 문자(SMS) 보내기

"접수되면 내 휴대폰에 진짜 문자가 오게" 하고 싶을 때. 유료 API가 필요한 심화 단계입니다.

💜 여기는 선택입니다. 앞의 무료 알림(활동 2: 실시간·브라우저·카톡)으로 대부분 충분합니다. 실제 문자(SMS)는 문자 발송 서비스 가입 + 소액 비용(건당 과금)이 필요해요. 원하는 분만 진행하세요.
내 신청 시스템에 '실제 휴대폰 문자(SMS)' 알림을 붙이고 싶어. 초보 기준으로 안내해줘. [해줘] 1) 국내에서 쓰기 쉬운 문자 발송 서비스(예: 알리고 등)와 대략적인 비용(건당) 비교 2) 가입 → 발신번호 등록(사전승인 필요) → API 키 발급까지의 순서 3) 새 신청이 들어오면 '나에게' 접수 문자, 또는 신청자에게 '접수 완료' 문자가 가게 연결 - API 키는 코드에 노출하지 말고 서버(환경변수/시크릿)에 저장 4) 카카오 알림톡과의 차이(더 싸지만 템플릿 승인 필요)도 한 줄 비교 내 스택에 맞춰 단계별로, 비용과 주의점(발신번호 승인)을 꼭 알려줘.
🤖 클로드에서 바로 이어 하기 →
📦 이 활동의 결과물 — 서버 검증으로 잠긴 관리자 페이지 + 엑셀 다운로드·기록 + (선택) 실제 문자. 이제 하나의 완성된 '신청 시스템'입니다.
🎤 강사 팁 (강사 전용) — 이 활동의 진짜 핵심은 "비번을 코드에 넣지 않는다" 한 가지입니다. if(pw==="1234")식으로 만들려는 학생을 꼭 잡아, "틀린 비번 → 데이터 안 보임"을 눈앞에서 시연하세요. SMS는 발신번호 사전 승인·건당 과금 때문에 당일 완성이 어려우니, "무료 알림으로 충분, 문자는 원하는 분만 숙제"로 정리하면 수업이 매끄럽습니다.
