신청 보안 4. 관리자 페이지 안전하게 잠그기

관리자 페이지엔 수강생 연락처(개인정보)가 있어요. 지금은 아직 제대로 안 잠겨 있습니다. 여기서 '서버 검증'으로 안전하게 잠그고, 명단을 엑셀로 내려받기까지 합니다.

⏱ 약 25분📥 입력 · 3번 관리자 페이지📦 결과물 · 안전하게 잠긴 관리자 페이지 + 엑셀

❓ 왜 이 활동을 하나요? — 3번에서 만든 관리자 페이지는 사실 아직 문을 안 잠근 상태예요. 그 안엔 수강생 연락처가 들어 있어서, 안 잠그면 누구나 볼 수 있습니다. 그래서 여기서 잠급니다. 비번을 페이지에 그냥 적으면(예: if 비번=="1234") '소스 보기'로 뚫려요 → 그래서 서버에서 검증하는 안전한 방식으로 잠급니다. "이미 만들었다"고 느끼는 그 페이지에 자물쇠를 다는 단계예요. (접수 알림·문자는 앞 3번에서 이미 다뤘습니다.)
0 준비·설계1 모집·신청 페이지2 저장 연결3 관리자·알림4 안전·엑셀5 5분 복제6 후기
1안전한 로그인 — 서버 검증 (이게 핵심)

틀린 비번으로는 신청 데이터가 아예 안 보이게 만드는 것이 목표입니다.

⚠️ 이렇게 하면 안 됩니다 — 페이지 코드에 if(비번==="1234")처럼 넣기. 누구나 브라우저 '소스 보기'로 비번을 읽고 들어옵니다. 가장 흔한 실수예요.
내 관리자 페이지 로그인을 '서버 검증' 방식으로 안전하게 만들어줘. 나는 코딩을 몰라. (페이지에 비번 넣기 금지) [내 상황] (아는 만큼 적기) · 관리자 페이지: 신청1~3에서 만든 내 페이지에 있어 · 저장 방식: 구글시트 / Supabase / 잘 모름 · 사이트: 클로드로 만든 페이지 / Netlify / 기타 [해줘] 1) 비밀번호를 페이지 코드가 아니라 '서버(예: Supabase Edge Function)의 시크릿/환경변수'에 저장 2) 로그인 때 입력한 비번을 서버로 보내 검증 → 맞을 때만 신청 목록을 내려주기 (틀리면 못 들어가고, 신청 데이터는 애초에 브라우저로 안 내려오게) 3) 신청 데이터도 아무나 못 읽게(RLS/서비스키로 서버에서만 읽기) 4) 왜 이 방식이 안전한지 한 줄로 [진행 방식 — 나는 초보라 천천히] · 한 단계씩만, 내가 "다음" 할 때까지 기다려줘 · 어느 버튼·메뉴를 누르는지, '무엇을 어디에 붙여넣는지'(파일 이름·위치까지) 콕 집어서 쉬운 말로 · 막히거나 화면이 다르면 내가 '화면 캡처(스크린샷)'를 붙여넣을게 → 그 화면 보고 "여기 누르세요" 알려줘 · 에러가 뜨면 그대로 붙여넣을 테니 쉽게 풀어서 해결법을 먼저 내 저장 방식·사이트를 물어보고 1단계부터 시작해줘.
📌 복사한 다음, 이렇게 하세요
  1. 위 '복사' 버튼을 누릅니다.
  2. 관리자 페이지를 만들었던 그 클로드(claude.ai) 대화창에 붙여넣습니다. — 같은 대화에 이어서 하면 클로드가 내 페이지를 기억해요. (새 대화라면 "내 관리자 페이지 코드야"라며 내 페이지 코드도 같이 붙여넣기)
  3. 붙여넣으면 클로드가 한 단계씩 물어보고 알려줍니다 — "비번을 어디 저장할지", "Supabase에서 어디를 누를지" 등. 시키는 대로 하나씩 따라가세요.
  4. 막히거나 화면이 달라 보이면, 그 화면을 캡처해서 클로드에 붙여넣고 "여기서 뭘 누르면 되나요?"라고 물어보세요. 에러가 뜨면 그 글자도 그대로 붙여넣으면 됩니다.
  5. 다 되면 테스트 — 일부러 틀린 비번을 넣어보세요. 신청 목록이 안 보이면 성공이에요. ✅

2엑셀 다운로드 & 기록 (실무 도구)

접수 명단을 엑셀로 내려받아 출석부·정산에 쓰고, 처리 기록(상태·메모)을 남깁니다.

  • 구글시트로 저장했다면 — 이미 시트가 곧 엑셀입니다(파일 → 다운로드 → Excel). 관리자 페이지에 '시트 열기' 버튼만 달면 끝.
  • Supabase로 저장했다면 — 관리자 페이지에 '엑셀(CSV) 다운로드' 버튼을 붙여 현재 목록을 내려받게 합니다.
내 관리자 페이지에서 신청 명단을 엑셀로 내려받고, 처리 기록을 남기게 해줘. 나는 초보라 하나씩 알려줘. [해줘] 1) '엑셀 다운로드' 버튼: 현재 화면의 신청 목록(필터·체크박스로 고른 것)을 CSV/엑셀로 저장 - 컬럼: 이름·연락처·신청항목·상태·메모·접수일시 2) 상태 변경(대기→연락함→확정)과 메모가 저장되고, '누가 언제 바꿨는지' 기록이 남게 3) 개인정보라 다운로드 파일 취급 주의 문구 한 줄(외부 공유·방치 금지) 내 저장 방식(구글시트/Supabase)에 맞게 버튼과 방법을 만들어줘. 막히면 화면 캡처를 붙여넣을게.
⚠️ 다운로드한 엑셀도 개인정보입니다. 아무 폴더에 방치하거나 외부에 공유하지 말고, 강의가 끝나 목적이 사라지면 보관 기준에 따라 정리하세요.

이 활동의 진짜 핵심은 단 하나, "비번을 코드에 넣지 않는다(서버 검증)"입니다. 학생 대부분이 if(pw==="1234")식으로 만들려 하니 꼭 잡아, "틀린 비번 → 데이터 안 보임"을 눈앞에서 시연하세요. 엑셀은 실무 편의. 막히면 화면 캡처를 클로드에 붙여넣게 하면 대부분 스스로 풉니다.
