브랜딩 배포 05. 배포 & 나만의 도메인(가비아)

완성한 페이지를 인터넷에 배포하고, 나만의 브랜드 주소(예: mycolor.com)를 가비아에서 사서 연결합니다. 자물쇠(https)까지 켜면 진짜 내 사이트가 됩니다.

⏱ 약 30분📥 입력 · 완성된 페이지(04)📦 결과물 · 나만의 도메인 라이브

✅ 이미 기본 배포(넷플리) 경험이 있다면 2단계 도메인부터 집중하세요. 도메인이 있어야 명함·인스타에 내 주소를 당당히 넣을 수 있습니다.
01 브랜드 분석02 전략·키워드03 구조·메뉴 04 페이지 고도화05 배포·도메인06 브랜딩 마스터
1배포 — 인터넷에 올리기

완성한 페이지를 넷플리(Netlify)에 올려 기본주소(xxxxxx.netlify.app)를 받습니다.

  • 넷플리에 페이지 파일을 올리면 바로 인터넷 주소가 생깁니다.
  • 이미 배포해 본 적이 있다면, 기존 사이트에 업데이트만 하면 됩니다.
2도메인 이름 정하기

주소는 한 번 정하면 오래 씁니다. 짧고, 내 브랜드가 들어가게.

  • 짧고 외우기 쉽게 · 내 이름·브랜드 포함(예: choihaesuk, pbscolor)
  • 하이픈(-)·숫자는 피하고, 끝자리는 .com 또는 .kr
내 브랜드에 어울리는 도메인(웹사이트 주소) 이름을 추천해줘. - 내가 하는 일: - 브랜드/활동명: - 원하는 느낌(깔끔한/전문적인/기억하기 쉬운): 조건: 1) 짧고 외우기 쉽게(영어 스펠링 포함) 2) .com/.kr 중 추천과 이유 3) 후보 8개를 표로: 도메인 | 읽는 법 | 추천 이유 4) 이미 많이 쓰일 것 같은 건 표시
3가비아에서 도메인 구입

아래 버튼으로 가비아에서 검색·구매하세요. (연 1~2만원대)

🔗 가비아에서 도메인 검색하기 →
  1. 검색창에 원하는 주소 입력(예: mycolor.com)
  2. 초록색 「등록 가능」 → 신청하기 → 장바구니
  3. 등록 기간 1년 선택 → 로그인/가입 → 결제
  4. 구입 후 「My가비아 → 도메인 → 관리」 화면을 열어둡니다.
💡 결제·로그인은 대표님이 직접 하세요. (AI·강사에게 비밀번호·카드번호를 넘기지 않습니다.)
4도메인 연결 + 자물쇠(https)

넷플리에 "이 주소를 내 사이트에 붙여줘"라고 알려주는 단계입니다.

  • 넷플리 → Domain management → Add a domain → 내 도메인 입력
🟢 방법 A. 네임서버를 넷플리로 (권장·쉬움) 넷플리가 준 네임서버 4개를 가비아 「네임서버 설정」에 입력.
🔵 방법 B. DNS 레코드 직접 가비아 「DNS 관리」에서 넷플리 안내대로 A·CNAME 입력.
  • 연결되면 넷플리 HTTPS에서 인증서 자동 발급 → Force HTTPS 켜기 → 주소창에 🔒
⏳ 연결은 보통 몇 분~몇 시간(길면 하루) 걸립니다. 바로 안 돼도 정상입니다.

🤖 혼자 어렵나요? 클로드가 화면 보며 도와줍니다

🤖 클로드 코워크 열기 →
[역할] 너는 내 웹사이트에 '도메인'을 연결해 주는 도우미야. 브라우저로 화면을 보며 단계별로 도와줘. [내 상황] - 도메인 산 곳: 가비아 - 내 도메인 주소: - 넷플리 기본주소: xxxxxx.netlify.app [해줘] 1) 넷플리에서 도메인 추가 화면까지 안내하고 눌러야 할 버튼을 짚어줘. 2) 가비아에서 '네임서버' 또는 'DNS 레코드'를 넷플리 값으로 바꾸는 위치를 클릭 순서대로. 3) 연결되면 https(자물쇠)가 켜졌는지 확인해줘. 안 되면 원인과 해결을 쉬운 말로. ※ 로그인·비밀번호·결제는 내가 직접 할게. 너는 안내와 확인만.
📦 이 활동의 결과물 — 나만의 도메인으로 열리는 라이브 홈페이지
➡ 다음 06 활동 입력 — 이 홈페이지를 근거로 브랜딩 자산(마스터 단어·키워드·해시태그)을 정리합니다.
🎤 강사 팁 (강사 전용) — 연결 대기시간(전파) 때문에 "안 된다"는 문의가 많습니다. 기다리면 된다고 먼저 안내하세요. 비밀번호·결제는 반드시 본인이 하게 하고, 강사·AI가 대신 입력하지 않도록 짚어 주세요.
