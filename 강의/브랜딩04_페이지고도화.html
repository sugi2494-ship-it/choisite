브랜딩 고도화 04. 페이지별 내용·디자인 고도화

03의 메뉴 구조표를 보고 페이지(섹션)를 하나씩 실제 내용으로 채웁니다. 카피·구성·신뢰요소·버튼까지, 그리고 검색 키워드가 자연스럽게 들어가 노출도 챙깁니다.

⏱ 약 25분📥 입력 · 메뉴 구조표(03)📦 결과물 · 페이지별 완성 내용

🧩 한 번에 한 섹션씩 하세요. 히어로 → 소개 → 문의 3개를 먼저 완성하면 페이지가 살아납니다. 과장·미검증 실적은 금지, 사실만.

1메뉴 구조표 불러오기

03에서 만든 메뉴 구조표를 준비하고, 지금 만들 섹션을 하나 고릅니다.

  • 03의 메뉴 구조표를 붙여넣습니다(또는 같은 채팅 이어서).
  • 먼저 만들 섹션을 고릅니다 — 추천 순서: 홈 히어로 → 소개(이력·신뢰) → 문의.
2페이지(섹션) 고도화 프롬프트 — 반복 사용

섹션 이름만 바꿔가며 반복해서 쓰면, 모든 페이지가 완성됩니다.

너는 전환율 높은 웹 카피라이터 겸 디자이너야. 아래 '메뉴 구조표'에서 지금 만들 섹션 하나를 골라, 실제 넣을 내용을 완성해줘. 나는 이미 활동 중인 인플루언서/강사이고, 목표는 '노출 → 방문 → 문의·신청'이야. [붙여넣기] - 메뉴 구조표(03): - 지금 만들 섹션 이름: [해줘] 1) 헤드라인 후보 3개 — 검색 키워드가 자연스럽게 들어가게(노출) 2) 본문 카피 — 방문자의 고민에 공감 → 내 해결책 → 얻는 결과 순서로 3) 넣을 요소 — 사진/후기/숫자(실적)/버튼 등 무엇을 어디에 4) 이 섹션의 행동 버튼 문구 1개 5) 모바일용 짧은 요약본 ※ 과장·미검증 실적은 쓰지 말고, 실제 사실만. 톤은 따뜻하고 전문적으로.
🧩 완성되면 "다음 섹션은 OO" 하고 같은 프롬프트를 반복하세요. 한 섹션이 마음에 들 때까지 다듬은 뒤 넘어갑니다.
3전체 톤·일관성 점검

섹션을 다 채웠으면, 페이지 전체가 하나의 톤으로 읽히는지 점검합니다.

지금까지 만든 페이지 섹션들을 모아서 전체를 점검해줘. 1) 말투·톤이 처음부터 끝까지 일관된가 (아니면 통일안 제시) 2) 02의 '핵심 메시지 3개'가 페이지 곳곳에 반복되나 3) 검색 키워드가 자연스럽게 들어갔나(노출) — 어색하면 다듬기 4) 방문자가 3초 안에 "뭐 하는 사람인지" 알 수 있나 5) 어느 화면에서든 '문의·신청' 버튼이 보이나 6) 모바일에서 너무 길지 않은가 — 줄일 곳 제안 고칠 점을 우선순위로 3가지만 콕 집어줘.
✅ 이 정도면 통과 — 히어로·소개·문의가 완성되고, 3초 안에 정체가 읽히며, 문의 버튼이 어디서나 보이면 배포로 갑니다.
