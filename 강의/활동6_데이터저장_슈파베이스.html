활동 6. 데이터 저장하기 · 슈파베이스(Supabase) 연결

설문·문의·신청 내용을 저장하려면 데이터가 담길 창고(데이터베이스)가 필요합니다. 가장 쉬운 무료 도구가 Supabase(슈파베이스)예요. 이 사이트도 Supabase를 씁니다.

슈파베이스가 뭔가요?

입력받은 내용(이름·연락처·설문 답변 등)을 안전하게 저장해 두는 무료 창고입니다. 엑셀 대신 인터넷에 저장된다고 생각하시면 됩니다. 가입만 하면 바로 쓸 수 있어요.

1) 가입하고 프로젝트 만들기

구글 계정으로 1분이면 가입됩니다.

  • 아래 Supabase 열기 → Start your project 로 가입/로그인
  • New Project 눌러 프로젝트 이름·비밀번호 정하고 생성 (1~2분 대기)
  • 프로젝트가 만들어지면 준비 끝!
🟢 Supabase 열기 →
2) 연결값(URL·키) 찾기

웹페이지와 연결하려면 두 가지 값이 필요합니다.

  • 왼쪽 메뉴 맨 아래 Settings(설정) → API 로 이동
  • Project URL 복사 (예: https://xxxx.supabase.co)
  • anon public 키 복사 — 이 두 개를 클로드에게 주면 됩니다.
💡 anon public 키는 웹에 넣어도 되는 공개용입니다. 단, service_role 키는 절대 웹페이지·프롬프트에 넣지 마세요(비밀 키).
1내 폼을 Supabase에 저장되게 연결
내 웹페이지의 문의 폼(이름·연락처·문의내용)이 Supabase에 저장되게 연결해줘.
- 내 Supabase 정보: URL은 [여기에 붙여넣기], anon key는 [여기에 붙여넣기]
- 테이블 이름은 contacts 로, 없으면 만들고 필요한 컬럼도 만들어줘
- 방문자(익명)가 저장할 수 있도록 보안(RLS) 설정 방법도 초보자용으로 알려줘.
2저장이 안 될 때 (오류 해결)
방금 만든 Supabase 저장이 안 돼.
오류 메시지는 이거야: [여기에 붙여넣기]
초보자가 이해할 수 있게 원인과 해결 방법을 하나씩 알려주고, 코드도 고쳐줘.
