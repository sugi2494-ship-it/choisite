AI 웹페이지 하루 만에 만들기

AI 기초 30분

약 30분
🎯 목표

생성형 AI가 처음이어도, 프롬프트를 ‘복사·붙여넣기’로 다룰 수 있게 몸을 풉니다.

👩‍🏫 강사 진행
  • Claude 화면 소개 — 어디에 쓰고, 어떻게 답이 나오는지 시연
  • 프롬프트 = ‘AI에게 주는 지시문’ 개념 설명, 좋은 지시의 예시
  • 간단한 프롬프트 하나를 다 같이 복사→붙여넣기→결과 확인 (성공 경험)
✍️ 수강생 실습

아래 예시 프롬프트를 붙여넣어 답을 받아본다. “되네!”를 경험한다.

💬 예시 프롬프트 (준비운동)
안녕! 나는 웹페이지를 처음 만들어보는 강사야. 생성형 AI가 처음이라 아주 쉽게 설명해줘. 먼저 내 소개를 멋지게 3문장으로 써줘. · 나는 [퍼스널컬러 강사]이고, · [30~50대 여성]을 대상으로, · [나에게 어울리는 색과 스타일을 찾아주는] 일을 해. (대괄호 안은 내 상황으로 바꿔서 넣을게.)
✅ 통과 기준
  • Claude에 프롬프트를 넣고 답을 받아봄
④

활동 0. 나 발견하기

약 30–40분
🎯 목표

‘나는 누구를 어떻게 돕는가’ + 이 홈페이지의 목적과 넣을 메뉴까지 한 번에 정리합니다. (여기서 나온 요약이 다음 활동의 재료)

👩‍🏫 강사 진행
  • 어려운 질문(‘강점은?’) 대신 쉬운 질문에 답하게 → 강점 색이 자동 계산됨
  • G·H 섹션(홈페이지 목적 / 넣을 메뉴)까지 꼭 채우게 안내
  • 맨 아래 요약 복사하기는 안 눌러도 됩니다 — 활동 1에서 바로 이어집니다
✍️ 수강생 실습 (빈칸 정리)
· 나의 대상 :
· 나의 강점(한 문장) :
· 홈페이지 목적 :
· 넣을 메뉴 :
✅ 통과 기준
  • 강점 색 결과가 나옴
  • 홈페이지 목적·메뉴가 정해짐
⑤

활동 1. 웹페이지 방향 설정

약 30분
🎯 목표

목표(무엇을 얻을 것인가)를 정하고, 그에 맞는 구조·메뉴를 짜서 ‘나만의 홈페이지 프롬프트’를 완성합니다.

👩‍🏫 강사 진행
  • 1번 ‘얻고 싶은 결과’를 최대 2개 선택 → 2번에서 필요한 메뉴가 자동 제안됨
  • 3번 이름·연락처(전화·이메일·카톡)를 꼭 적게 안내 — 연락 통로가 없으면 목표가 안 이뤄짐
  • 사진은 지금 넣지 말고 바탕화면 ‘사진’ 폴더에 모아두라고 안내 (페이지엔 자리만)
  • 맨 아래에서 프롬프트 생성 → 복사
✍️ 수강생 실습

생성된 프롬프트를 복사해 둔다. (다음 단계에서 사용)

✅ 통과 기준
  • 목표·메뉴 확정
  • 이름·연락처 입력
  • 프롬프트 복사 완료
⑥

활동 2. 페이지 만들기

약 40분
🎯 목표

복사한 프롬프트를 Claude에 넣어 첫 웹페이지를 실제로 만들어냅니다.

👩‍🏫 강사 진행
  • Claude에 프롬프트 붙여넣기 → 결과(HTML) 확인 시연
  • 사진은 ‘자리(회색 박스)’만 두게 안내, 내용은 활동 0 요약으로 채워지게
  • 막히면 화면 캡처를 Claude에 붙여 물어보는 요령 알려주기
✍️ 수강생 실습

내 프롬프트로 첫 페이지 생성 → 눈으로 확인. (활동 1에서 만든 프롬프트가 있으면 그걸 쓰고, 없으면 아래 기본형을 채워 쓰세요.)

💬 예시 프롬프트 (기본 제작형)
너는 한국어로 답하는 웹 개발 도우미야. 아래 정보로 코딩을 모르는 사람도 쓸 수 있는 '한 페이지짜리 웹사이트(index.html)'를 완성해줘. 조건: HTML·CSS·JS를 하나의 파일에 넣고, 모바일에서도 예쁘게, 한글 줄바꿈이 자연스럽게(word-break:keep-all) 만들어줘. [홈페이지 이름]: [나의 소개·강점 한 문장]: ← 활동 0 결과 [대상(누구를 돕나)]: [핵심 목표]: ← 예) 강의 신청 받기 / 상담 문의 받기 [필요한 메뉴]: ← 예) 홈·소개·강의·후기·문의 [이름·연락처]: 이름 / 전화 / 이메일 / 카톡 [분위기]: ← 예) 따뜻하고 신뢰감 있는 사진은 지금 넣지 말고 '회색 자리 박스 + 어떤 사진인지 한 줄 설명'만 만들어줘.
✅ 통과 기준
  • 내 이름·메뉴가 들어간 페이지가 화면에 보임
⑦

활동 3. 다듬고 연결하기

약 40분
🎯 목표

문구·디자인을 다듬고, 메뉴·버튼·연락 통로가 실제로 연결되게 만듭니다.

👩‍🏫 강사 진행
  • 어색한 문장·색·간격을 프롬프트로 고치는 방법 (‘이 부분을 이렇게 바꿔줘’)
  • 메뉴 클릭 시 이동, 전화·카톡 버튼 연결 확인
  • 모바일에서도 예쁜지 점검
💬 예시 프롬프트 (수정·연결)
방금 만든 페이지를 이렇게 다듬어줘. 1) [소개 문단]을 더 따뜻하고 전문가답게 다시 써줘. 2) 상단 메뉴를 누르면 해당 위치로 부드럽게 이동하게 해줘. 3) '문의하기' 버튼을 누르면 내 전화(010-0000-0000)와 카톡(링크)으로 연결되게 해줘. 4) 전체 색을 [핑크 계열]로 통일하고, 글자 간격·여백을 보기 좋게 정리해줘. 5) 휴대폰에서도 깨지지 않게 확인해줘.
✅ 통과 기준
  • 메뉴·연락 버튼이 눌러짐
  • 모바일 화면 정상
⑧

활동 4. 배포하고 내 주소 만들기

약 40분
🎯 목표

내 컴퓨터 안의 파일을 인터넷 어디서나 열리는 진짜 사이트로 배포하고, 내 주소(도메인)를 갖습니다.

👩‍🏫 강사 진행
  • 배포 방법 시연 (예: GitHub → Vercel), 생성된 주소 확인
  • 바탕화면 ‘사진’ 폴더의 사진을 자리표시 위치에 하나씩 넣기
  • 원하면 나만의 도메인(가비아 등) 연결 안내
💬 예시 프롬프트 (사진 자리 · 오류 해결)
① 사진 자리 만들기 이 페이지에 프로필 사진과 강의 사진이 들어갈 자리를 만들어줘. 지금은 회색 박스로 두고, 각 자리에 '여기에 어떤 사진'인지 한 줄로 표시해줘. 나중에 내 사진 파일로 바꿀 거야. ② 오류가 나면 (캡처를 붙여넣고) 이 화면을 캡처해서 붙여넣을게. 무슨 뜻이고, 코딩을 모르는 내가 어떻게 고치면 되는지 순서대로 아주 쉽게 알려줘.
✍️ 내 주소 적기
내 웹페이지 주소 : https://
✅ 통과 기준
  • 휴대폰으로 내 주소가 열림
⑨

활동 5. 내 페이지 알리기

약 30분
🎯 목표

만든 페이지가 검색되고 사람들에게 닿도록 첫걸음을 놓습니다.

👩‍🏫 강사 진행
  • 네이버·구글에 사이트 등록(검색 노출)하는 법 안내
  • 인스타·블로그·카톡 프로필에 내 주소 공유
  • 다음 단계 예고 — 검색·홍보를 더 키우는 브랜딩 과정으로 연결
💬 예시 프롬프트 (검색·홍보 문구)
내 웹페이지가 네이버·구글에서 잘 검색되도록, · 페이지 제목(<title>)과 · 메타 설명(description)과 · 키워드를 만들어줘. 내 일은 [퍼스널컬러 강사], 지역은 [울산]이야. 그리고 이 페이지를 인스타·카톡에 공유할 때 쓸 짧은 홍보 문구도 3가지 버전으로 만들어줘.
✅ 통과 기준
  • 검색 등록 신청함
  • SNS/프로필에 주소 공유함
🎓 여기까지가 하루 완성 코스입니다. “검색·홍보로 고객이 오게”까지 원하면 AI 웹페이지 브랜딩 고도화 과정, “남을 가르치는 강사로”까지 원하면 마스터 전문가과정으로 이어집니다.
