마스터 4. 수강생만 들어오게 — 안전 잠금

등록한 수강생만 강의실·자료에 들어오게 비밀번호 잠금을 걸고(화면이 아니라 서버가 검증), 강사 전용 자료는 비공개로 보호합니다.

⏱ 약 30분📥 입력 · 2·3단계 강의실📦 결과물 · 서버검증 잠금 + 자료실

💡 왜 서버검증인가요? 화면(브라우저)에서만 비번을 확인하면 조금만 아는 사람은 뚫습니다. 유료 강의라면 서버가 진짜인지 확인해야 자료가 안 새요.

1화면 검증 vs 서버 검증

같은 '비밀번호'라도 어디서 확인하느냐가 안전을 가릅니다.

  • ❌ 화면 검증 — 비번이 페이지 코드 안에 있음 → 조금만 아는 사람은 우회
  • ✅ 서버 검증 — 비번을 서버(슈파베이스 Edge Function)가 확인 → 통과해야 자료 URL을 내줌
🔑 지금 이 사이트의 강의실도 서버검증으로 잠급니다. 같은 방식을 내 강의실에도 적용해요.
2서버검증 잠금 걸기

AI에게 한 단계씩 손잡고 만들어 달라고 합니다. 이 부분은 서버를 다뤄서 조금 어렵습니다.

너는 나를 1:1로 돕는 친절한 개발 도우미야. 나는 코딩을 전혀 모르는 왕초보야. '등록 수강생만 들어오는 서버검증 잠금'을 한 번에 한 단계씩만 안내해줘. 규칙: (1) 한 번에 한 단계만, 내가 "됐어" 하면 다음으로. (2) 어려운 말은 쉬운 말로. (3) 어디를 누르는지 화면 기준으로. (4) 내가 화면을 캡처해 보여주면 그걸 보고 알려줘. 원하는 것: - 화면이 아니라 서버(슈파베이스 Edge Function)가 비밀번호를 확인 - 맞으면 강의실/자료를 열고, 통과하면 일정 시간 다시 안 물어봄(세션) - 비번은 코드에 넣지 말고 서버 비밀값(Secret/환경변수)으로 이 순서로: 1) 슈파베이스에서 Edge Function 만들기 — 어디서 만드는지 + 붙여넣을 코드를 그대로 줘 2) 비밀번호를 Secret(환경변수)에 넣는 위치 — 값은 내가 직접 넣을게 3) 내 강의실 페이지에서 이 함수를 불러 통과/실패를 처리하는 코드 4) 시험 — 맞는 비번/틀린 비번으로 확인 각 단계 끝에 "여기까지 됐으면 알려줘"라고 물어봐줘.
🔒 비밀번호 값 자체는 강사 본인이 직접 입력·관리하세요. 프롬프트·페이지 코드에 비번을 그대로 쓰지 않습니다.
💡 Edge Function은 파일·서버 배포가 필요해 채팅만으론 까다롭습니다. 아래 클로드 코워크로 하면 파일을 직접 만들어 줘서 훨씬 쉽고, 막히면 대표(최해숙)에게 서버검증 연결을 요청하세요.

3자료실 공개/비공개 나누기

맛보기는 공개, 진짜 자료는 통과한 수강생만.

내 강의실 자료를 '공개'와 '비공개'로 나눠줘. - 공개(누구나): 과정 소개, 맛보기 1장, 커리큘럼 - 비공개(통과한 수강생만): 강의 PDF, 워크시트, 강사 전용 자료 - 비공개 자료는 로그인(비번 통과) 후에만 다운로드 링크가 보이게 (링크만 알면 받아지는 일 없게) 공개/비공개를 나중에 내가 쉽게 바꾸는 방법도 알려줘.
