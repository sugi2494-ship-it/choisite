마스터 6-3. 신청자·수강생 관리

들어온 신청을 표로 보고, 상태(대기·확정·취소)를 관리하고, 명단을 저장하고, 확정자를 수강생으로 챙깁니다. 구글시트만으로도 충분해요.

⏱ 약 30분📥 입력 · 6-1 신청 데이터📦 결과물 · 신청 관리대장

💡 신청 폼이 '받는 곳'이라면 여기는 '처리하는 곳'입니다. 구글폼을 썼다면 관리도 구글시트에서 바로 하면 돼요.

🔑 구글폼(A)으로 받았다면 — 관리자 페이지 없이 구글시트에서 바로 관리해도 됩니다: 시트에 '상태' 열을 추가해 대기/확정/취소를 적고, 필터·정렬로 보고, 파일 → 다운로드 → .csv(엑셀)로 저장. 아래 1~2번은 그 방법, 3~4번은 슈파베이스(B)로 내 사이트에 관리자 페이지를 두는 경우입니다.
1🟢 A. 구글시트로 관리 (구글폼 사용 시·쉬움)

새 시트나 프로그램 없이, 응답 시트를 그대로 관리대장으로 씁니다.

  • 응답 시트 맨 오른쪽에 '상태' 열 추가 → 대기/확정/취소 적기
  • '메모' 열 추가 → "입금 확인" 같은 기록
  • 상단 데이터 → 필터 만들기로 상태별 보기·정렬
  • 파일 → 다운로드 → .csv/엑셀로 명단 저장(출석부)
내 구글시트(강의 신청 응답)를 관리하기 좋게 정리하는 법을 알려줘. 나는 왕초보야. - '상태'(대기/확정/취소)와 '메모' 열을 추가하는 법 - 상태별로 색이 자동으로 바뀌게(조건부 서식) 하는 법 — 누를 위치까지 - 확정된 사람만 한눈에 보게 필터 거는 법 - 이름/연락처로 빠르게 찾는 법 그림 그리듯 한 단계씩, 쉬운 말로.
2개인정보 지키기 (꼭)

신청자 명단은 개인정보입니다.

🔒 시트 공유 범위를 '나만'으로 두세요(링크 있는 모두 X). 내려받은 엑셀 파일은 아무 데나 두지 말고, 화면·파일을 남에게 공유하지 마세요. 연락처는 꼭 필요한 사람만.
3🔵 B. 관리자 페이지 만들기 (슈파베이스 사용 시)

나만 비번으로 들어가, 신청을 실시간 표로 봅니다.

너는 나를 1:1로 돕는 친절한 개발 도우미야. 나는 왕초보야. 슈파베이스 applications 표를 보는 '관리자 페이지'를 한 단계씩 만들어줘. (쉬운 말, 누를 위치까지) - 나만 비밀번호로 들어가는 페이지(가능하면 4단계 서버검증) - 신청을 표로: 신청시간·이름·연락처·관심과정·하고 싶은 말 - 새 신청은 맨 위에 실시간으로, 최신순 + 검색창 - 각 신청에 상태 버튼(대기/확정/취소)·메모 저장, 상태별 개수 요약 내 슈파베이스: URL [붙여넣기], anon key [붙여넣기] 각 단계 끝에 "여기까지 됐으면 알려줘"라고 물어봐줘.
🤖 클로드 코워크로 함께 만들기 (파일·서버 직접 연결) →
4확정자 = 수강생, 진행 챙기기

'확정'된 사람은 이제 수강생입니다.

  • 확정 수강생에게 강의실 입장 비번·안내 보내기(4단계 잠금과 연결)
  • 진행 표시: 미시작 / 진행중 / 수료(시트에 열 추가 또는 관리자 페이지)
  • 수료하면 후기 요청(6-6과 연결)
확정된 수강생에게 보낼 '강의실 입장 안내' 메시지를 만들어줘. - 따뜻한 인사 + 축하 - 강의실 주소와 입장 비밀번호 넣을 자리 [ ] - 첫 활동을 언제까지 해오면 되는지 - 막히면 어떻게 도움받는지(화면 캡처해서 질문) 문자/카톡으로 보낼 짧은 버전과, 조금 자세한 버전 둘 다.
🤖 클로드에서 바로 이어 하기 →
📦 결과물 — 신청 관리대장(상태·메모·진행) + 입장 안내 메시지
