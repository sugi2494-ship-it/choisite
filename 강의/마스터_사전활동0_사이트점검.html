[점검 요청 — 아래 5개 영역을 각각 진단해줘] 1. 보안: https 적용 여부, 코드에 노출된 비밀번호·API 키, 관리자 페이지 보호, 문의/신청 폼의 스팸·개인정보 처리, 넷플리 환경변수 사용 여부. 2. 정리·구조: 메뉴가 직관적인지, 불필요·중복 페이지, 안 쓰는 파일, 모바일에서 깨지는 곳, 방문자가 3초 안에 "뭐 하는 곳인지" 아는지. 3. 기업형 완성도: 브랜드(색·폰트·로고) 일관성, 신뢰 요소(연락처·사업자정보·후기·실적), 로딩 속도, 전문적으로 보이려면 보완할 점. 4. SEO(검색 노출): 페이지 제목·설명 메타태그, 공유 썸네일(OG), sitemap.xml·robots.txt 유무, 제목 태그(H1) 구조, 모바일 최적화, 그리고 네이버·구글·빙에 사이트 등록이 돼 있는지. 5. 홍보·마케팅 활성화: 방문자를 고객으로 만드는 행동유도(CTA), 문의·접수로 이어지는 동선, 카드뉴스·SNS·블로그 연결, 재방문 유도, 지금 놓치고 있는 마케팅 기회.
