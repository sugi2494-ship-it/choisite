활동 7. 설문·문의 폼 + 결과 다운로드 관리자

간단한 설문/문의 폼을 만들고, 받은 답변을 관리자 페이지에서 보고 엑셀(CSV)로 내려받는 단계입니다. (저장은 활동 6의 Supabase 연결이 되어 있어야 해요.)

1간단한 설문지 폼 만들기
방문자가 답할 수 있는 간단한 설문지 폼을 만들어줘.
- 질문 예시: 이름, 연락처, "어떤 강의에 관심 있으세요?"(객관식), "바라는 점"(주관식)
- 제출하면 Supabase 테이블 survey_responses 에 저장되게
- 제출 후 "감사합니다" 화면이 뜨게.
(질문은 내가 나중에 바꿀 수 있게 알기 쉽게 만들어줘.)
2결과 보는 관리자 페이지 + 엑셀 다운로드
설문/문의 결과를 볼 수 있는 관리자 페이지를 만들어줘.
- 비밀번호를 입력해야 들어갈 수 있게
- 받은 답변을 표(리스트)로 보여주고
- 맨 위에 "엑셀(CSV) 다운로드" 버튼을 넣어서 클릭하면 전체 결과가 파일로 저장되게.
3새 접수 실시간 표시
관리자 페이지에서 새 설문/문의가 들어오면 자동으로 목록 맨 위에 뜨고, 살짝 소리나 색으로 표시되게 해줘. (새로고침 안 해도 보이게)
4문의/신청도 같은 방식으로
문의하기·수강신청 폼도 같은 방식으로 Supabase에 저장되게 하고, 관리자 페이지 한 곳에서 설문·문의·신청을 탭으로 나눠 볼 수 있게 해줘.
💡 접수 알림을 내 휴대폰(텔레그램 등)으로 바로 받는 것도 가능합니다. 강사(최해숙 대표)에게 "실시간 알림 연결"을 요청하세요 — 별도로 설정해 드립니다.
