ACTIVITY 04

배포하고 내 주소 만들기

검색 노출과 카톡 대표이미지를 넣은 뒤, 두 가지 방법 중 편한 것으로 인터넷에 올립니다.

Before upload

올리기 전에 넣을 두 가지

둘 다 화면에는 보이지 않는 <head> 안에 들어갑니다. 디자인은 그대로입니다.

검색에 잘 나오게 (SEO)

네이버·구글 검색에 내 페이지가 걸리게 만듭니다. 배포 직전에 하세요.

검색 노출 프롬프트
지금 만든 내 페이지에 이어서, 검색에 잘 나오게 <head>를 채워줘. (화면 디자인은 그대로 두고) · 제목(title): [내 업종 + 지역 + 이름] 형태로, 검색에 잘 걸리게 · 설명(description): 한 문장으로, 결론부터 (누가 무엇을 해주는 곳인지) · 지역 키워드: 화면 첫인상엔 크게 드러내지 말고, 메타(설명·구조화데이터)에는 내 지역을 넣어줘 · 구조화데이터(JSON-LD): 내 업종에 맞게 LocalBusiness(지역업체) 또는 Person(전문가) + 자주 묻는 질문(FAQ) · 없는 정보(주소·전화·평점)는 지어내지 말고 빈칸으로 둬줘.

카톡에 뜰 대표이미지

링크를 보낼 때 뜨는 이미지입니다. 배포 전에 미리 심어둬야 공유하는 순간 예쁘게 뜹니다.

대표이미지 프롬프트
지금 만든 내 페이지에, 카톡·페북·문자로 링크를 공유할 때 뜨는 대표이미지를 넣어줘. (화면 디자인은 그대로 두고) · <head>에 og:image, og:title, og:description, twitter:card(summary_large_image)를 넣어줘. · 대표이미지가 없으면, 눈에 띄는 색 배경에 [상호·이름 + 한 줄 소개]가 크게 들어간 가로형 이미지(1200x630)를 만들어줘. · 이미지 파일은 페이지와 같은 폴더에 넣고, 주소를 정확히 연결해줘. · 없는 로고·사진은 지어내지 말고, 색과 글자로 깔끔하게 만들어줘.

링크를 카톡에 붙였는데 이미지가 안 뜨면, 카톡이 예전 정보를 기억하고 있어서입니다. 잠시 뒤 다시 붙여넣거나 주소 끝에 ?1을 붙여 보세요.

Choose

넷리파이와 버셀, 무엇이 다를까

넷리파이 드롭버셀 + GitHub
쉬움폴더를 끌어다 놓기만 하면 끝가입과 연결이 필요
GitHub없어도 됨필요 (연결하면 강력)
수정 반영같은 사이트에 다시 드래그파일만 고쳐 올리면 자동 배포
추천오늘 바로 확인하고 싶을 때계속 운영하고 수정할 때

추천 순서. 오늘은 넷리파이 드롭으로 5분 만에 내 링크를 만들어 보고, 계속 쓸 거라면 버셀과 GitHub로 옮기면 됩니다. 둘 다 무료로 시작합니다.

Method A

넷리파이 드롭 — 가장 쉬운 방법

  1. netlify.com에 무료 가입한 뒤 로그인합니다.
  2. app.netlify.com/drop을 엽니다.
  3. 내 HTML 파일(또는 폴더)을 화면에 끌어다 놓습니다.
  4. 잠시 후 OOO.netlify.app 주소가 생기면 완성입니다. 그 링크가 내 홈페이지입니다.

수정한 파일을 다시 올릴 때

  1. 클로드에서 고친 HTML 파일을 새로 내려받습니다.
  2. app.netlify.com에 로그인해 내 사이트를 클릭해 들어갑니다.
  3. 화면을 아래로 내려 Production deploys 칸을 찾습니다.
  4. 그 안의 Drag and drop your site output folder here 영역에 고친 파일을 끌어다 놓습니다.
  5. 잠깐 기다리면 같은 주소 그대로 내용만 새로 바뀝니다.

주의. 처음 올렸던 app.netlify.com/drop 화면에 또 놓으면 다른 주소가 새로 생깁니다. 꼭 내 사이트 안으로 들어가서 올리세요.

Method B

버셀 + GitHub — 계속 운영할 때

먼저 GitHub에 가입합니다

GitHub는 내 파일을 저장해 두는 인터넷 창고입니다. 버셀이 이 창고에서 파일을 가져다 웹페이지로 띄워 줍니다.

  1. github.com/signup에서 무료 가입합니다.
  2. 새 저장소(New repository)를 만들고 내 HTML 파일을 올립니다. (Add file → Upload files)

버셀에 연결해 자동 배포합니다

  1. vercel.com을 열고 Continue with GitHub를 눌러 GitHub 계정으로 가입합니다.
  2. GitHub가 Authorize Vercel 창을 띄우면 눌러서 연결을 허용합니다.
  3. 버셀에서 Add New → Project로 들어가, 만들어 둔 저장소 옆의 Import를 누릅니다.
  4. 설정은 그대로 두고 Deploy를 누릅니다. (정적 HTML은 손댈 것이 없습니다)
  5. 잠시 후 OOO.vercel.app 주소가 완성됩니다. 이제 GitHub에 파일만 고쳐 올리면 자동으로 반영됩니다.

저장소가 목록에 안 보이면 Import 화면의 Adjust GitHub App Permissions에서 내 저장소를 선택해 접근을 허용하면 나타납니다.

나만의 도메인은 어떻게 하나요

이 과정은 무료 주소(OOO.netlify.app / OOO.vercel.app)로 마무리합니다. 그 주소로도 충분히 공유하고 홍보할 수 있습니다. 내 도메인 구입과 연결은 마케팅(브랜딩) 과정에서 함께 배웁니다.

  • 내 주소 확인하고 저장
