배포하고 내 주소 만들기
인터넷에 올려 링크 받기

"배포"는 내 페이지를 진짜 인터넷 주소(링크)로 만드는 거예요. 먼저 검색에 잘 나오게 한 뒤, 두 가지 방법 중 편한 걸로 올리면 됩니다.

먼저 · 올리기 전에 "검색 노출" 넣기
🔎

검색에 잘 나오게 (SEO)

검색 노출용 정보는 페이지의 <head>에 들어갑니다. 화면 디자인은 안 바뀌어요. 아래를 복사해 같은 대화에 붙여넣으면 클로드가 넣어 줍니다. 배포 직전에 하세요.

Q. SEO가 뭐예요?
SEO = 네이버·구글 검색에 내 페이지가 잘 걸리게 만드는 것 (제목·설명·키워드·공유이미지). 화면이 아니라 <head> 안에 들어가서, 보기엔 그대로예요.
※ AI 검색에 인용되게 하는 GEO와 더 넓은 마케팅은 마케팅(브랜딩) 과정에서 다뤄요.
🖼️

카톡에 뜰 대표이미지 넣기

카톡·문자로 링크를 보낼 때 뜨는 대표이미지예요. 이건 배포 전에 페이지 안에 미리 심어둬야 공유하는 순간 예쁘게 떠요. 아래를 복사해 같은 대화에 붙여넣으세요.

💡 링크를 카톡에 붙였는데 이미지가 안 뜨면 — 카톡이 예전 정보를 기억하고 있어서예요. 잠시 뒤 다시 붙여넣거나, 주소 끝에 ?1을 붙여 보세요.
넷리파이 vs 버셀 — 뭐가 다를까?
넷리파이 드롭버셀 (+GitHub)
쉬움⭐⭐⭐ 폴더 드래그만⭐⭐ 가입·연결 필요
GitHub없어도 됨필요(연결하면 강력)
수정 반영같은 사이트에 다시 드래그파일 고쳐 올리면 자동 배포
추천 상황오늘 바로 확인하고 싶을 때계속 운영·수정할 홈페이지
💡 추천 순서: 오늘은 넷리파이 드롭으로 5분 만에 내 링크를 만들어 보고 → 계속 쓸 거면 버셀+GitHub로 옮기면 됩니다. 둘 다 무료로 시작해요.
방법 A · 가장 쉬운 넷리파이 드롭
Netlify Drop

드래그 한 번으로 올리기

GitHub 없이, 폴더를 끌어다 놓기만 하면 끝나요.

  1. netlify.com에 무료 가입 후 로그인
  2. app.netlify.com/drop 열기
  3. 내 HTML 파일(또는 폴더)을 화면에 끌어다 놓기
  4. 잠시 후 OOO.netlify.app 주소가 생기면 완성! 그 링크가 내 홈페이지예요.
🔁 수정한 파일을 다시 올릴 땐? (그대로 따라하기)
  1. 클로드에서 고친 HTML 파일을 새로 내려받아요 (내 컴퓨터에 저장).
  2. app.netlify.com에 로그인 → 내 사이트(방금 만든 것)를 클릭해서 들어가요.
  3. 사이트 화면을 아래로 내리면 "Production deploys"(프로덕션 배포) 칸이 있어요.
  4. 그 안의 "Drag and drop your site output folder here" 영역에 고친 파일(폴더)을 끌어다 놓기.
  5. 잠깐 기다리면 같은 주소 그대로 내용만 새로 바뀝니다. 끝!
⚠️ app.netlify.com/drop(맨 처음 올렸던 그 화면)에 또 놓으면 다른 주소가 새로 생겨요. 꼭 내 사이트 안으로 들어가서 위 4번 자리에 올리세요.
방법 B · 계속 운영할 땐 버셀 + GitHub
GitHub

먼저 GitHub 가입

GitHub는 내 파일을 저장해 두는 인터넷 창고예요. 버셀이 이 창고에서 파일을 가져다 웹페이지로 띄워 줍니다.

  1. github.com/signup에서 무료 가입 (이메일·비밀번호)
  2. 가입 후 새 저장소(New repository)를 만들고, 내 HTML 파일을 업로드 (Add file → Upload files)
Vercel

버셀에 연결해서 자동 배포

GitHub와 연결해 두면, 파일만 고쳐 올려도 알아서 다시 배포돼요. (그대로 따라하기)

  1. vercel.com 열기 → "Continue with GitHub"(GitHub로 계속)를 눌러 GitHub 계정으로 가입해요.
  2. 처음엔 GitHub가 "Authorize Vercel"(버셀 허용) 창을 띄워요 → Authorize 눌러 연결 허용.
  3. 버셀에서 Add New → Project → 내 저장소 목록이 뜨면, 아까 만든 저장소 옆 Import 클릭.
  4. 설정은 그대로 두고(정적 HTML이면 손댈 것 없음) Deploy 클릭.
  5. 잠시 후 OOO.vercel.app 주소 완성! 이제부턴 GitHub에 파일만 고쳐 올리면 자동으로 새 내용이 반영돼요.
💡 저장소가 안 보이면, Import 화면의 "Adjust GitHub App Permissions"(또는 Configure)에서 내 저장소를 선택해 접근을 허용하면 나타나요.
💡 더 간단히 시험만 하려면 vercel.com/drop에 드래그도 돼요. 단, 드롭은 올릴 때마다 새 주소가 생겨서, 계속 운영할 거면 위 GitHub 연결 방식을 권해요.
🌐 나만의 도메인(예: 내이름.com)은요?
이 과정은 무료 주소(OOO.netlify.app / OOO.vercel.app)로 마무리해요. 그 주소로도 충분히 공유·홍보할 수 있어요. 내 도메인 구입·연결은 조금 더 나아간 단계라, 마케팅(브랜딩) 과정에서 함께 배웁니다.

내 인터넷 주소가 생겼나요?

이제 이 링크를 검색·SNS에 알려서 손님이 오게 할 차례예요.
