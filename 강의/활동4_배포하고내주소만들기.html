활동 4. 배포하고 내 주소 만들기

지금 만든 페이지는 아직 나만 볼 수 있습니다. 이제 인터넷에 올려서, 누구나 들어올 수 있는 나만의 주소를 만듭니다. 무료이고, 10분이면 됩니다.

0 / 6 단계
먼저

'배포'가 뭔가요?

어려운 말 같지만 아주 간단합니다

이렇게 생각하세요
지금까지는 내 방 안에 그림을 그린 것입니다.
배포는 그 그림을 가게에 걸고, 가게 주소를 갖는 것이에요.
그래야 남에게 "여기 와서 보세요"라고 할 수 있습니다.

오늘 쓰는 도구 3가지의 역할을 정리하면 이렇습니다.

✍️
Claude (클로드)페이지를 만들어주는 사람
🪟
Chrome (크롬)페이지를 보는 창문
🏠
Netlify (넷리파이) 또는 Vercel (버셀)인터넷에 올려주고 주소를 내주는 곳 — 오늘 새로 배웁니다. 둘 중 하나만 쓰면 됩니다

💰 둘 다 무료입니다. 내 페이지 하나 올리는 정도는 돈이 들지 않아요.

📌 이름이 어려워 보이지만 하는 일은 똑같습니다. 내 파일을 받아서 인터넷 주소를 만들어주는 곳이에요.

STEP 1

내 페이지 파일 받기

클로드에서 파일 하나를 내려받습니다

지금 페이지는 클로드 화면 안에 있습니다. 이걸 파일로 내려받아야 인터넷에 올릴 수 있어요.

★파일로 만들어 달라고 하기▾
지금까지 만든 웹페이지를 인터넷에 올리려고 해. index.html 이라는 이름의 파일 하나로 만들어서 내려받게 해줘. - 사진과 로고가 파일 안에 같이 들어가서, 다른 컴퓨터에서 열어도 그대로 보이게 해줘. - 파일은 딱 하나만 만들어줘.

파일 이름은 꼭 index.html 이어야 합니다. 이 이름이어야 주소를 열었을 때 바로 보여요.

  • 내려받은 파일은 바탕화면이나 다운로드 폴더에 있습니다.
  • 파일을 두 번 눌러 열어보세요. 크롬에서 내 페이지가 뜨면 성공입니다.

⚠️ 파일을 열었는데 사진이 안 보인다면, 아직 인터넷에 올려도 똑같이 안 보입니다. 아래 「문제 해결」의 사진 항목을 먼저 보세요.

😊 고민되면 Netlify(넷리파이)로 하세요. 처음 하시는 분께는 이쪽이 훨씬 편합니다. 나중에 다른 곳으로 옮기는 것도 얼마든지 가능해요.

고르셨나요? 아래에서 눌러주세요. 그에 맞는 방법만 보여드립니다.

STEP 3

파일 올리고 주소 받기

여기까지 하면 내 주소가 생깁니다

Netlify · 끌어다 놓기 3단계
파일을 끌어다 놓으면 바로 주소가 나옵니다.
🟢 넷리파이 드롭 바로 열기 새 창으로 열립니다 · 이 화면은 그대로 두세요
  1. 위 버튼을 누르면 넷리파이 드롭 화면이 열립니다.
    → 화면 가운데에 파일을 놓으라는 큰 상자가 보입니다.
  2. 받아둔 index.html 파일을 그 상자 위로 끌어다 놓습니다.
    → 잘 안 되면 index.html을 폴더 하나에 넣고, 그 폴더째 끌어다 놓으세요.
  3. 잠시 기다리면 주소가 바로 만들어집니다. 눌러서 확인하세요.
  4. 주소를 계속 쓰려면 가입하라고 나옵니다. 구글 계정으로 가입하면 그 주소가 내 것이 됩니다.
    ⚠️ 가입하지 않으면 주소가 임시로만 유지됩니다. 꼭 가입하세요.
이런 주소가 생깁니다
https://내가정한이름.netlify.app

✏️ 주소가 이상한 영어로 나왔다면, Site settings → Change site name에서 원하는 이름으로 바꿀 수 있습니다.

Vercel · 가입하고 올리기
먼저 가입한 뒤 파일을 올립니다.

① 가입하기

  1. 크롬에서 vercel.com 으로 들어갑니다.
  2. Sign Up(가입)을 누르고, 구글 계정으로 가입하는 게 가장 쉽습니다.
  3. 용도를 물으면 개인(Hobby / Personal)을 고르세요. 이게 무료입니다.

② 파일 올리기

  1. 첫 화면에서 새로 만들기(Add New / New Project)를 누릅니다.
  2. 파일을 직접 올리는 배포(Deploy) 화면으로 들어갑니다.
  3. index.html 파일을 끌어다 놓습니다. (폴더째 올려도 됩니다)
  4. 1분 내로 완료 화면이 나옵니다.
이런 주소가 생깁니다
https://내가정한이름.vercel.app

✏️ 주소 이름은 Settings → Domains에서 바꿀 수 있습니다.

⚠️ 두 곳 모두 화면 구성이 수시로 바뀝니다. 버튼 위치보다 「올린다 → 주소가 나온다 → 확인한다」 이 흐름만 기억하세요.

💡 화면이 영어라 당황스러우면 크롬에서 마우스 오른쪽 → 한국어로 번역을 쓰세요.

STEP 4

주소 확인하고 이름 다듬기

기억하기 좋은 주소로 바꿉니다

  • 생긴 주소를 눌러서 내 페이지가 잘 뜨는지 확인합니다.
  • 휴대폰에서도 꼭 열어보세요. 주소를 나에게 카톡으로 보내면 간단합니다.
  • 주소가 너무 복잡하면 설정(Settings) → Domains에서 이름을 바꿀 수 있습니다.

✏️ 주소 이름 짓기 요령 — 영어로 짧고 기억하기 쉽게. 이름·브랜드명을 쓰면 좋아요. (예: haesook-color, pbscolor)

문제 해결

이럴 때는 이렇게

수업에서 가장 자주 나오는 상황

사진이 안 보여요

가장 흔한 문제입니다. 사진이 파일 안에 포함되지 않아서 그래요. 클로드에 이렇게 말하세요.

사진이 안 보여. 사진을 파일 안에 함께 넣어서 다른 컴퓨터에서 열어도 보이도록 index.html을 다시 만들어줘.
주소를 열었는데 빈 화면이거나 목록만 나와요

파일 이름이 index.html이 아닐 가능성이 큽니다. 파일 이름을 정확히 index.html로 바꾸고 다시 올려보세요. (대문자·띄어쓰기·한글 없이)

파일 이름에 한글이 들어가 있어요

한글 파일명은 문제를 일으킬 수 있습니다. index.html로 바꿔주세요.

휴대폰에서 이상하게 보여요

클로드로 돌아가 아래처럼 고친 뒤, 새 파일을 받아 다시 올리세요.

휴대폰 화면에서 글자가 잘리고 답답해 보여. 휴대폰에서 잘 보이도록 전체를 정리하고 index.html 파일을 다시 만들어줘.
Netlify와 Vercel 중 뭘 써야 할지 모르겠어요

처음이시면 Netlify를 쓰세요. 파일을 끌어다 놓기만 하면 주소가 나옵니다. 둘 다 무료이고, 나중에 옮기는 것도 얼마든지 가능합니다.

이미 한쪽에 올렸다면 그대로 쓰시면 됩니다. 굳이 옮길 필요 없어요.

Vercel 화면이 영어라 모르겠어요

크롬에서 화면 아무 곳이나 마우스 오른쪽 클릭 → 한국어로 번역을 누르세요. 대부분 한글로 바뀝니다. Netlify도 마찬가지입니다.

내 도메인(예: 내이름.com)을 쓰고 싶어요

가능합니다. 다만 도메인을 따로 구입해야 하고(연 1~2만원대), 연결 설정이 필요합니다. 오늘은 netlify.app / vercel.app 주소로 충분합니다. 나중에 필요할 때 도전하세요.
