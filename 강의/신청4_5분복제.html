신청 확장 5. 5분 만에 새 교육 신청서 만들기

한 번 만든 신청 시스템을 복제해서 제목·날짜·가격만 바꾸면 새 특강 신청서가 5분이면 나옵니다. 이제 특강 하나가 상품 하나예요.

⏱ 약 15분📥 입력 · 완성된 신청 시스템📦 결과물 · 새 교육 신청서 1개 + 양산 루틴

♻️ 핵심 아이디어: 처음 하나만 제대로 만들면, 다음부터는 복사 → 몇 군데만 수정이면 끝. 새 특강을 열 때마다 처음부터 만들 필요가 없습니다.
0 준비·설계1 모집·신청 페이지2 저장 연결3 관리자·알림4 안전·엑셀5 5분 복제
1복제하고 몇 군데만 바꾸기

기존 모집·신청 페이지를 그대로 복사한 뒤, 바뀌는 것만 교체합니다.

  • 바꾸는 것 (보통 이것만) — 특강 제목 · 한 문장 소개 · 날짜/시간 · 장소 · 정원 · 가격 · 신청 마감일
  • 그대로 두는 것 — 폼 구조, 관리자 화면, 알림, 로그인(서버 검증) — 다시 만들 필요 없음
내가 만든 '교육 신청 페이지'를 복제해서 새 특강용으로 바꿔줘. [해줘] 1) 기존 모집·신청 페이지를 복사해 새 파일로 만들기(파일명/주소 규칙도 추천) 2) 아래만 새 값으로 교체: 특강 제목 / 한 문장 소개 / 날짜·시간 / 장소 / 정원 / 가격 / 마감일 3) 폼·관리자·알림·로그인 구조는 그대로 재사용 (다시 만들지 말 것) 4) 바꿔야 할 곳을 '체크리스트'로 정리해줘 (빠뜨리기 쉬운 곳 표시) [새 특강 정보] (여기에 새 특강의 제목·날짜·가격 등만 붙여넣기)
💡 자주 여는 특강이라면 '빈칸 템플릿'을 하나 만들어 두세요. 제목·날짜·가격만 채우면 되는 양식이면 진짜 5분입니다.
2새 신청이 섞이지 않게 저장 분리

여러 특강을 열면 어느 신청이 어느 특강인지 구분돼야 관리가 됩니다.

여러 특강을 운영할 때 신청이 섞이지 않게 정리해줘. [해줘] 1) 각 신청에 '교육명(또는 특강코드)' 항목을 자동으로 붙여 저장(신청자는 안 적어도 되게) 2) 관리자 페이지에서 '교육별 필터'로 특강마다 명단·인원·상태를 따로 보기 3) 방법 비교: (A) 특강마다 시트/탭 분리 (B) 한 곳에 모으고 '교육명'으로 필터 - 내 상황에 뭐가 편한지 추천 4) 새 특강을 추가할 때 뭘 하면 되는지 3줄 요약
